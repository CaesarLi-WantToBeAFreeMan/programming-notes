## 013. lambda

* a **short** block of code that takes parameters and returns a value or performs an action
* **similar** to a `method` but `anonymous` (**without a name**)
* introduced in `Java 8` to support `functional programming` (`FP`) and to provide a clear and concise way to represent instances of functional interfaces (interfaces with a `single abstract method`)
* implement functional interfaces `implicitly`
* improve **code readability** and **reduce boilerplate**, especially in `collections` and `event handling`

### lambda expression syntax

1. empty parameter with a statement

```java
    () -> statement;
```

2. empty parameter with multiple statements

```java
    () -> {
        statements;
    }
```

3. single parameter with a statement

```java
    parameter -> statement;
```

4. single parameter with multiple statements

```java
    parameter -> {
        parameters;
    }
```

5. multiple parameters with a statement

```java
    (parameters) -> statement;
```

6. multiple parameters with multiple statements

```java
    (parameters) -> {
        statements;
    }
```

### `functional interfaces`

* an `interface` with **only one** `abstract` method
* provide the `implementation` of the `single abstract method` of a `functional interface`
* these interfaces can have **multiple** `default` or `static` methods, but **only one** `abstract` method

#### example

* `Greet.java`

```java
    public interface Greet{
        void greet(String name);//only abstract method

        default void helloWorld(){//a default method
            System.out.println("Hello,World!");
        }

        static void helloCaesar(){//a static method
            System.out.println("Hello Caesar");
        }
    }
```

* `Main.java`

```java
    public class Main{
        public static void main(String [] args){
            Greet.helloCaesar();//invoke static method
            Greet greet = name -> System.out.println("Hello " + name);
            greet.helloWorld();//invoke default method
            greet.greet("James");//invoke abstract method
        }
    }
```

#### `Java`'s build-in `functional interfaces`

##### `Customer`

* take input, return **nothing**

###### methods

1. `void accept(T t)`
    * perform this operation on the given argument
2. `default Consumer <T> andThen(Consumer <? super T> after)`
    * return a composed `Consumer` that performs, in sequence, this operation followed by the after operation

###### example

```java
    public class Main{
        public static void main(String [] args){
            Consumer <String> consumer = name -> System.out.print("Hello " + name + "\t"),
                              consumer1 = name -> System.out.println(name.toUpperCase()),
                              consumer2 = consumer.andThen(consumer1);
            consumer2.accept("Caesar");//Hello Caesar   CAESAR
        }
    }
```

###### other functional interfaces

1. `IntConsumer`: `(int value)`
2. `LongConsumer`: `(long value)`
3. `DoubleConsumer`: `(double value)`
4. `BiConsumer`: `(T t, U u)`
5. `ObjIntConsumer`: `(T t, int value)`, and no default `andThen` method
6. `ObjLongConsumer`: `(T t, long value)`, and no default `andThen` method
7. `ObjDoubleConsumer`: `(T t, double value)`, and no default `andThen` method
8. ...

##### `Supplier`

* take nothing, return **a result**

###### methods

1. `T get()`: get a result

###### example

```java
    import java.time.LocalDateTime;
    import java.time.format.DateTimeFormatter;
    import java.util.function.Supplier;

    public class Main{
        public static void main(String [] args){
            Supplier <LocalDateTime> localDateTimeSupplier = () -> LocalDateTime.now();
            System.out.println(localDateTimeSupplier.get().format(DateTimeFormatter.ofPattern("LLL dd, yyyy\tKK:mm:ss a")));
        }
    }
```

###### other functional interfaces

1. `BooleanSupplier`: `boolean getAsBoolean()`
2. `IntSupplier`: `int getAsInt()`
3. `LongSupplier`: `long getAsLong()`
4. `DoubleSupplier`: `double getAsDouble()`

##### `Function`

* take **one input**, return **one output**

###### methods

1. `default <V> Function <T, V> andThen(Function <? super R, ? extends V> after)`: return a composed function that first applies this function to its input, and then applies the after function to the result
2. `R apply(T t)`: apply this function to the given argument
3. `default <V> Function<V, R> compose(Function <? super V, ? extends T> before)`: return a composed function that first applies the before function to its input, and then applies this function to the result
4. `static <T> Function <T, T> identity()`: return a function that always returns its input argument

###### example

```java
    import java.util.function.Function;

    public class Main{
        public static void main(String [] args){
            Function <String, Integer> stringToLength = words -> words.length();
            Function <Integer, String> lengthToMessage = size -> "size:\t" + size;
            Function <String, String> stringToMessage = stringToLength.andThen(lengthToMessage);
            stringToMessage = stringToMessage.compose(words -> words.toUpperCase());
            System.out.println(Function.identity().apply("Caesar") + "'s " + stringToMessage.apply("Caesar"));
        }
    }
```
