## 002. variables

### meaning

* variables are divided into `primitive types` and `reference types`
* Java is `strongly typed programming language` so the type of every variable **must be declared**

### primitive types

#### meaning

* there're `8` `primitive types`
* hold an **actual values**
* stored in the **stack memory** (for `local variable`)

| type      | size      | default       | description                   |
| :-------: | :-------: | :-----------: | :-------------------------------: |
| `byte`    | `8-bit`   | `0`           | `smallest integer` type           |
| `short`   | `16-bit`  | `0`           | `small integer` type              |
| `int`     | `32-bit`  | `0`           | `default integer` type            |
| `long`    | `64-bit`  | `0L`          | `large integer` type              |
| `float`   | `32-bit`  | `0.0f`        | `single-precision` decimal        |
| `double`  | `64-bit`  | `0.0`         | `default floating-point` type     |
| `char`    | `16-bit`  | `'\u0000'`    | a `single` Unicode character      |
| `boolean` | `1-bit`   | `false`       | `logical` type (`true`/`false`)   |

#### declaration

1. declaration only
    * syntax: `primitiveType variableName;`
    * example

    ```java
        int integer;                //default value: 0
        double floatingPoint;       //default value: 0.0
        char character;             //default value: '\u0000'
        boolean booleanVariable;    //default value: false
    ```

2. declaration + initialization
    * syntax: `primitiveType variableName = initialValue;`
    * example

    ```java
        int integer = 1;
        double floatingPoint = 1.2;
        char character = 'a';
        char character1 = '臺';
        boolean booleanVariable = true;
    ```

3. multiple variable declaration
    * syntax: `primitiveType variableName = initialValue, variableName1 = initialValue1;`
    * example

    ```java
        int integer = 0, integer1 = 1, integer2 = 2;
    ```

4. resign
    * syntax: `variableName = value;`
    * example

    ```java
        int age;
        age = 18;
    ```

#### invoke variable

* syntax: `variableName`
* example
```java
    int age = 18;
    System.out.println("age:\t" + age);
```

### reference types

#### meaning

* all types other than `primitives` are `reference` types
* store a reference (`address`) to the object in `heap memory`
* include: `String`, `arrays`, `classes`, `interfaces`, `enums`, etc
* example

```java
    String name = "Caesar", name1;
    name1 = "James";
    System.out.println("Hello " + name);
    System.out.printf("Hello %s\n", name1);
```

### wrapper classes

#### meaning

* `wrapper classes` for all `primitive` types to allow them to be used as `objects`

| primitive | wrapper class |
| :-------: | :-----------: |
| `byte`	| `Byte`        |
| `short`	| `Short`       |
| `int`     | `Integer`     |
| `long`	| `Long`        |
| `float`	| `Float`       |
| `double`	| `Double`      |
| `char`	| `Character`   |
| `boolean` | `Boolean`     |

#### `autoboxing`

* automatically convert a `primitive` value into its corresponding `wrapper class object`
* happen
    1. assignment
    ```java
        Integer i = 10;     //seem as Integer i = Integer.valueOf(10)
    ```
    2. passing
    ```java
        public static void Main(String [] args){
            printInteger(12);
        }

        private void printInteger(Integer x){
            System.out.println(x);
        }
    ```
    3. adding
    ```java
        List <Integer> list = new ArrayList<>();
        list.add(12);       //seem as list.add(Integer.valueOf(12))
    ```

#### `unboxing`

* automatically convert a `wrapper class object` into its `primitive` value
* happen
    1. assignment
    ```java
        Integer i = 12;
        int x = i;      //seem as int x = i.intValue();
    ```
    2. using wrapper objects
    ```java
        Integer a = 10, b = 20;
        int sum = a + b;    //seem as int sum = a.intValue() + b.intValue()
    ```

### type casting

* convert a variable from one type to another

#### 1. widening casting (`implicit`)

* convert a **smaller** type to a **larger** type
* done **automatically** by `Java`
* **safe** and **no data loss or overflow**
* **cannot convert** `boolean` to or from any other type(**unlike** in `C++`)

| from\to   | `boolean` | `byte`    | `short`   | `char`    | `int` | `long`    | `float`   | `double`  |
| :-------: | :-------: | :-------: | :-------: | :-------: | :---: | :-------: | :-------: | :-------: |
| `byte`    | ❌        | ❌        | ✔         | ❌        | ✔     | ✔         | ✔         | ✔         |
| `short`   | ❌        | ❌        | ❌        | ❌        | ✔     | ✔         | ✔         | ✔         |
| `char`    | ❌        | ❌        | ❌        | ❌        | ✔     | ✔         | ✔         | ✔         |
| `int`     | ❌        | ❌        | ❌        | ❌        | ❌    | ✔         | ✔         | ✔         |
| `long`    | ❌        | ❌        | ❌        | ❌        | ❌    | ❌        | ✔         | ✔         |
| `float`   | ❌        | ❌        | ❌        | ❌        | ❌    | ❌        | ❌        | ✔         |
| `double`  | ❌        | ❌        | ❌        | ❌        | ❌    | ❌        | ❌        | ❌        |
 
* example

```java
    int integer0 = 1;
    double double0 = integer0;//automatic widening
    System.out.println(double0);//1.0
```

#### 2. narrowing casting (`explicit`)

* convert a **larger** type to a **smaller** type
* done **manually** using `cast operator`
* may cause **data loss** or **overflow**
* syntax: `(typeName)variableName` 
* **cannot** convert `boolean` to or from any other type

| from\to   | `boolean` | `byte`    | `short`   | `char`    | `int` | `long`    | `float`   | `double`  |
| :-------: | :-------: | :-------: | :-------: | :-------: | :---: | :-------: | :-------: | :-------: |
| `byte`    | ❌        | ❌        | ✔         | ❌        | ✔     | ✔         | ✔         | ✔         |
| `short`   | ❌        | ✔         | ❌        | ✔         | ✔     | ✔         | ✔         | ✔         |
| `char`    | ❌        | ✔         | ✔         | ❌        | ✔     | ✔         | ✔         | ✔         |
| `int`     | ❌        | ✔         | ✔         | ✔         | ❌    | ✔         | ✔         | ✔         |
| `long`    | ❌        | ✔         | ✔         | ✔         | ✔     | ❌        | ✔         | ✔         |
| `float`   | ❌        | ✔         | ✔         | ✔         | ✔     | ✔         | ❌        | ✔         |
| `double`  | ❌        | ✔         | ✔         | ✔         | ✔     | ✔         | ✔         | ❌        |

* example

```java
    int integer0 = Integer.MAX_VALUE;
    short short0 = (short)integer0;//manual narrowing
    System.out.println(short0);//-1(overflow)
```

#### 3. character casting

* convert a character to an ASCII/Unicode code point

* example

```java
    char asciiChar = 'a',
            unicodeChar = '臺';
    //char to int is done automatically by Java
    int asciiInt = (int)asciiChar,//97
        unicodeInt = unicodeChar;//33,274
    System.out.println(asciiChar + ":\t" + asciiInt);
    System.out.println(unicodeChar + ":\t" + unicodeInt);
```

#### 4. object casting

* used for `reference types`
* use when working with inheritance (see [`basicOOP.md`]())
* syntax: `(ClassName)objectName`

* example

```java
    Object object = "Hello, World!";
    String string = (String)object;
    System.out.println(string);
```

#### 5. `var`

* supported since `Java 10`
* used for **local variable type inference**
* the type is **inferred at compile time** from the **right-hand side**
* `var` is **not a keyword**, but a **reserved type name**
* work **only for local variables**
* cannot be used **without initialization**
* cannot be used for `method parameters`, `fields` or `return types`

* example

```java
    var nums = new int [] {1, 2, 3, 4, 5};//int [] nums = new int [] {1, 2, 3, 4, 5}
    var name = "Caesar";//String name = "Caesar";
```

#### 6. `final`

* must be **assigned once only**
* modifiable
    * `primitive`: `value` is **constant**
    * `reference`: `reference` is **constant**, but `object data` **can be changed**

* example

```java
    final int num = 3;
    final List <Integer> nums = new ArrayList<>();
    //num = 4;  cannot change value
    System.out.println("final int:\t" + num);

    //nums = new ArrayList<>(Arrays.asList(1, 2, 3));   cannot change address
    nums.add(4);//add an element (modification) to the reference
    System.out.println("final ArrayList:\t" + nums);
    nums.set(0, 0);//reassign the first element (modification) to the reference
    System.out.println("final ArrayList:\t" + nums);
    nums.remove(0);//remove the first element (modification) to the reference
    System.out.println("final ArrayList:\t" + nums);

    int num1 = 3;
    List <Integer> nums1 = new ArrayList<>();
    num1 = 4;//can change value
    System.out.println("int:\t" + num1);

    nums1 = new ArrayList<>(Arrays.asList(1, 2, 3));//can change address
    System.out.println("ArrayList:\t" + nums1);
    nums1.add(4);
    System.out.println("ArrayList:\t" + nums1);
    nums1.set(0, 0);
    System.out.println("ArrayList:\t" + nums1);
    nums1.remove(0);
    System.out.println("ArrayList:\t" + nums1);
```
