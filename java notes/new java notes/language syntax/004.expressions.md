## 004. Expressions

* expressions are a statement to do an operation

### 1. Arithmetic Expressions

| operator | name | description |
| :-: | :-: | :-: |
| `+` | addition | add two numbers |
| `-` | subtraction | subtract two numbers |
| `*` | multiplication | multiply two numbers |
| `/` | division | divide two numbers |
| `%` | modulo | remainder after division |
| `++` | increment | increase by 1 |
| `--` | decrement | decrease by 1 |

* `integer division` truncates the decimal part
* for positive numbers
$$7 / 2 = 3 \quad \text {means} \quad \left \lfloor \frac {7} {2} \right \rfloor = 3$$
* for negative numbers
$$-7 / 2 = -3 \quad \text{means} \quad \text {truncate} \left( \frac {-7} {2} \right) = -3$$

* example

```java
    int num = 1;//declare an integer variable and assign it the value 1
    System.out.println("num:\t" + num);//output the num value

    System.out.println("num + 2:\t" + (num + 2));//output: 1 + 2 = 3
    System.out.println("num - 3:\t" + (num - 3));//output: 1 - 3 = -2
    System.out.println("num * 4:\t" + (num * 4));//output: 1 * 4 = 4
    System.out.println("num / 5:\t" + (num / 5));//output: 1 / 5 = 0 (integer division)
    System.out.println("num / 5.0:\t" + (num / 5.0));//output: 1 / 5.0 = 0.2 (floating-point division)

    System.out.println("pre-increment value:\t" + ++num + "\tafter pre-increment value:\t" + num);//pre-increment -> increase the value by 1 before operation
    num = 1;//reset
    System.out.println("post-increment value:\t" + num++ + "\tafter post-increment value:\t" + num);//post-increment -> increase the value by 1 after operation
    num = 1;
    System.out.println("pre-decrement value:\t" + --num + "\tafter pre-decrement value:\t" + num);//pre-decrement -> decrease the value by 1 before operation
    num = 1;
    System.out.println("post-decrement value:\t" + num-- + "\tafter post-decrement value:\t" + num);//post-decrement -> decrease the value by 1 after operation
```

### 2. Logical Expressions

| operator | name | description |
| :-: | :-: | :-: |
| `&&` | logical AND | `true` if both `a` and `b` are `true` |
| `\|\|`| logical OR | `true` if neither `a` or `b` is `true` or both are `true` |
| `!` | logical NOT | invert a `boolean` value |

* example

```java
    boolean a = true, b = false;
    System.out.println("a && b:\t" + (a && b));//false
    System.out.println("a || b:\t" + (a || b));//true
    System.out.println("!a:\t" + (!a));//false
```

### 3. Bitwise Expressions

| operator | Name | description |
| :-: | :-: | :-: |
| `&` | bitwise AND | set each bit to `1` **only if both bits are `1`** |
| `\|` | bitwise OR | set each bit to `1` **if at least one of the bits is `1`** |
| `^` | bitwise XOR | set each bit to `1` **only if the bits are different** |
| `~` | bitwise NOT | **invert** each bit |
| `<<` | left shift | shift bits to the **left**, **filling in `0`s on the right** |
| `>>` | signed right shift | shift bits to the **right**, **preserving the sign bit** |
| `>>>` | unsigned right shift | shift bits to the **right**, **filling in `0`s on the left** |

* example

```java
    int a = -0xffc, b = 0xaaf, result;
    //String.format("%32s", Integer.toBinaryString(a)).replace(' ', '0') is used to replace all ' 's to '0's
    System.out.printf("a:\t%d\tits binary representation:\t%s\n", a, String.format("%32s", Integer.toBinaryString(a)).replace(' ', '0'));
    System.out.printf("b:\t%d\tits binary representation:\t%s\n", b, String.format("%32s", Integer.toBinaryString(b)).replace(' ', '0'));
    result = a & b;
    System.out.println("a & b:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = a | b;
    System.out.println("a | b:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = a ^ b;
    System.out.println("a ^ b:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = ~a;
    System.out.println("~a:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = a << 3;
    System.out.println("a << 3:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = a >> 3;
    System.out.println("a >> 3:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
    result = a >>> 3;
    System.out.println("a >>> 3:\t" + result + "\tits binary representation:\t" + Integer.toBinaryString(result));
```

### 4. Assignment Expressions

| operator | description |
| :-: | :-: |
| `=` | assign value of `b` to `a` |
| `+=` | `a = a + b` |
| `-=` | `a = a - b` |
| `*=` | `a = a * b` |
| `/=` | `a = a / b` |
| `%=` | `a = a % b` |
| `&=` | `a = a & b` |
| `\|=` | `a = a \| b` |
| `^=` | `a = a ^ b` |
| `<<=` | `a = a << b` |
| `>>=` | `a = a >> b` |
| `>>>=` | `a = a >>> b` |

* example
  
```java
    int a = 12;
    System.out.println("a\t" + a);
    a += 12;
    System.out.println("a += 12\t" + a);
    a -= 12;
    System.out.println("a -= 12\t" + a);
    a *= 12;
    System.out.println("a *= 12\t" + a);
    a /= 12;
    System.out.println("a /= 12\t" + a);
    a = -0xff;
    System.out.println("set a to " + a);
    a &= 12;
    System.out.println("a &= 12\t" + a);
    a = -0xff;
    a |= 12;
    System.out.println("a |= 12\t" + a);
    a = -0xff;
    a ^= 12;
    System.out.println("a ^= 12\t" + a);
    a = -0xff;
    a <<= 3;
    System.out.println("a <<= 3\t" + a);
    a = -0xff;
    a >>= 3;
    System.out.println("a >>= 3\t" + a);
    a = -0xff;
    a >>>= 3;
    System.out.println("a >>>= 3\t" + a);
```

### 5. Comparison Expressions

| operator | description |
| :-: | :-: |
| `==` | equal |
| `!=` | not equal |
| `>` | greater than |
| `<` | less than |
| `>=` | greater than or equal to |
| `<=` | less than or equal to |

* example

```java
    int num = 12;
    System.out.println("num == 12:\t" + (num == 12));
    System.out.println("num != 12:\t" + (num != 12));
    System.out.println("num > 12:\t" + (num > 12));
    System.out.println("num >= 12:\t" + (num >= 12));
    System.out.println("num < 12:\t" + (num < 12));
    System.out.println("num <= 12:\t" + (num <= 12));
```
