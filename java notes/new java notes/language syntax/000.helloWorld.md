## 000. Hello World

### `Hello World` program

```java
    public class className{
        public static void main(String [] args){
            //single line comment
            /*
            multi-line
            comment
            */
        }
    }
```

### program explanation

1. `public` is an access modifier that allows the class or method to **be accessed from other class**
2. `class` is a keyword used to define a class
3. `ClassName` is the name of a class. It should start with a **capital letter** by Java naming conventions
4. `static` means the method belongs to the class and can be run **without creating an object**
5. `main` is the name of the method that serves as the **entry point** of the program
6. `String` is a **reference data type** that represents a sequence of characters
7. `String []` is an array of strings (commonly used to store **command-line arguments**)
8. `args` is the name of the array that stores the **command-line arguments**
9. a **comment** is a note in the code meant to improve readability and is ignored by the compiler
