## 004. conditional statements

* perform different computations or actions or return different values depending on a condition

### 1. `if`, `else if`, `else` statements

* used to execute code **only if a condition is true**
* basic conditional statements
* you can omit `{}` for single-line blocks, but **this is discouraged to avoid bugs**
* syntax

```java
    if(condition){
        statements;
    }else if(condition){
        statements;
    }else
        statement;
```

* example

```java
    Scanner scanner = new Scanner(System.in);
    int score = scanner.nextInt();
    if(score < 60)
        System.out.println("Grade F");
    else if(score < 70){
        System.out.println("Grade D");
    }else if(score < 80){
        System.out.println("Grade C");
    }else if(score < 90){
        System.out.println("Grade B");
    }else{
        System.out.println("Grade A");
    }
    scanner.close();
```

### 2. `switch` statements

* cleaner alternative to multiple `if-else` chains when checking a single variable
* use `break` to prevent fall-through
* you **cannot** put a condition in a `case`, like `case age < 0`
* syntax

```java
    switch(variable){
        case value0:
            statements;
            break;
        case value1:
            statements;
            break;
        default:
            statements;
            break;//it is not required
    }
```

* example

```java
    Scanner scanner = new Scanner(System.in);
    int dayOfWeek = scanner.nextInt();
    switch(dayOfWeek){
        case 0:
            System.out.println("Sunday");
            break;
        case 1:
            System.out.println("Monday");
            break;
        case 2:
            System.out.println("Tuesday");
            break;
        case 3:
            System.out.println("Wednesday");
            break;
        case 4:
            System.out.println("Thursday");
            break;
        case 5:
            System.out.println("Friday");
            break;
        case 6:
            System.out.println("Saturday");
            break;
        default:
            System.out.println("Invalid input");
            break;
    }
    scanner.close();
```

### 3. new `switch` statements

* introduced in `Java14`
* an enhanced version of `switch` that can be used as either a **statement** or an **expression**.
* `expression form` allows `switch` to **return a value** directly
* more **concise**, **safe**, and **less error-prone** than traditional `switch`
* syntax

```java
    dataType dataName = switch(variable){
        case value0 -> returnedValue0;//single case -> single expression
        case value1, value2, value3 -> returnedValue1;//multiple cases -> single expression
        case value4 -> {//single case -> multiple expressions
            statements;
            yield returnedValue2;//required to return value
        }
        case value5, value6, value7 -> {//multiple cases -> multiple expressions
            statements;
            yield returnedValue3;
        }
        default -> returnedValue4;//fallback case
    }
```

* example

```java
    System.out.println("please enter an integer that represents a day of week:\t");
    Scanner scanner = new Scanner(System.in);
    int input = scanner.nextInt();

    String dayOfWeek = switch(input){
        case 1 -> "Monday";
        case 2 -> "Tuesday";
        case 3 -> {
            System.out.println("middle of the week");
            yield "Wednesday";
        }
        case 4 -> "Thursday";
        case 5 -> "Friday";
        case 6 -> {
            System.out.println("the first day of the weekend");
            yield "Saturday";
        }
        case 7 -> {
            System.out.println("the last day of the weekend");
            yield "Sunday";
        }
        case 0, 8 -> "please try again";
        default -> {
            System.out.println("invalid input");
            yield "please enter an integer in the range [1, 7]";
        }
    };

    System.out.println(dayOfWeek);
```

### 4. `ternary` (`? :`) statements

* a simple alternative to `if-else` statements for assigning or returning values
* syntax

```java
    condition ? valueIfTrue : valueIfFalse;
```

* example
```java
    Scanner scanner = new Scanner(System.in);
    int number = scanner.nextInt();
    System.out.println("it is an " + ((number & 1) != 0 ? "odd" : "even") + " number");//you can use number % 2 != 0 condition statement
    scanner.close();
```
