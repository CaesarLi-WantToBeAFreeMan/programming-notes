## 011. Methods

### Concepts

* blocks of code that perform a task and are invoked by name
* support `overloading`, `varargs`, and `lambda` expressions
* all arguments are `passed by value` (even **object references**)

### Traditional Methods

#### Definition

```java
    [accessModifier] [static] returnType methodName([parameters]){
        //method body
        [return returnedData;]
    }
```

* `[content]` means this part is optional
* `accessModifier`: we'll talk later in `basicOOP.md`
* `static`: we'll talk later in `static.md`
* `returnType`: data type of the method returned
    * types:
        1. `void`: return nothing (`none`)
        2. `non-void`: include `primitive types` (`byte`, `short`, `int`, `long`, `float`, `double`, `char` and `boolean`) and `reference types` (`String`, `ArrayList`, etc)
* `methodName`: name of a method
* `parameters`: input data to the method
* `method body`: statements inside the method
* `return returnedData`: data that should be returned, if the method is `non-void`

#### Invocation

```java
    methodName(parameters);
```

* `methodName`: name of a method
* `parameters`: data that should be passed to the method

#### Example

1. void method: greet

    ```java
        public class Main{
            public static void main(String [] args){
                greet();
            }

            private static void greet(){
                System.out.println("Hello!!!");
            }
        }
    ```

2. primitive: sum of two `int`s

    ```java
        public class Main{
            public static void main(String [] args){
                System.out.println(getSum(12, 21));
            }

            private static void getSum(int num0, int numn1){
                return num0 + num1;
            }
        }
    ```

3. reference#0: greet to a person

    ```java

                greet("Caesar James LEE");
            }

            private static void greet(String name){
                System.out.println("Hello " + name + "!");
    ```

### `varargs` (`...`)

* allow a method to accept **zero or more arguments** of the **same type**
* internally treated as a **1D array**
* only **one `varargs` parameter** is allowed per method, and it **must be the last parameter**

#### Syntax

```java
    [accessModifier] [static] returnType methodName([otherParameters], dataType ... varargsName){
        //statements
        [return returnData;]
    }
```

#### Example#1: Only `varargs`

```java
    public static void main(String [] args){
        int sum = getSum(12, 21, 0, -5, 3, 9, -7);
        System.out.println("getSum(sum):\t" + sum);
    }

    private static int getSum(int ... nums){
        int sum = 0;
        for(var num : nums){
            sum += num;
        }
        return sum;
    }
```

#### Example#2: Fixed Parameters and `varargs`

```java
    public static void main(String [] args){
        sum = getSumFromRange(1, 5, 12, 21, 0, -5, 3, 9, -7);
        System.out.println("getSumFromRange(sum):\t" + sum);
    }

    private static int getSumFromRange(int left, int right, int ... nums){
        if(left < 0 || right > nums.length || left >= right){
            System.out.println("invalid range!!!");//for exception-based handling, see exceptions.md
            return 0;
        }
        int sum = 0;
        for(int i = left; i < right; i++){
            sum += nums[i];
        }
        return sum;
    }
```

### Method Overloading

* define **multiple methods** with the **same name** but **different parameter lists**
* allow methods to perform similar but slightly varied tasks
* overloaded methods must differ by:
    1. **number of parameters**
    2. **type of parameters**
    3. **order of parameters**
* **return type alone cannot** distinguish overloaded methods

#### Syntax

```java
    [accessModifier] [static] returnType methodName([parameterList]){
        //statements
        [return returnedData;]
    }
```

#### Example

```java
    public static void main(String [] args){
        System.out.println("\nno parameter:\n");
        greet();

        System.out.println("\none string parameter:\n");
        greet("Caesar");

        System.out.println("\nvarargs (multiple names):\n");
        greet("Caesar", "James", "John", "Lisa", "Linda", "Alice", "Jackson");

        System.out.println("\nstring and int parameters:\n");
        greet("Caesar", 3);
    }

    private static void greet(){//only greet
        System.out.println("Hi");
    }

    private static void greet(String name){//greet one person
        System.out.println("Hi " + name);
    }

    private static void greet(String ... names){//greet many people
        for(var name : names){
            System.out.println("Hi " + name);
        }
    }

    private static void greet(String name, int times){//greet one person multiple times
        while(times-- > 0){
            System.out.println("Hi " + name);
        }
    }
```

### Recursive Methods

* a method that **calls itself**
* must have a **base case** to avoid infinite recursion

#### Syntax

```java
    [accessModifier] [static] returnType methodName([parameters]){
        if(baseCase){
            return [returnedData];//escape the method
        }
        return methodName([modifiedParameters]);//recall the method
    }
```

#### Example#1: Countdown

```java
    public static void main(String [] args){
        countdown(10);
    }

    private static void countdown(int num){
        if(num <= 0){
            return;
        }
        System.out.println(num);
        countdown(num - 1);
    }
```

#### Example#2: Calculate Factorial Result

```java
    public static void main(String [] args){
        try{//see exceptions.md
            System.out.println(factorial(21));
        }catch(IllegalArgumentException e){//see exceptions.md
            System.out.println("invalid input:\t" + e);
        }
    }

    private static long factorial(int num){
        if(num < 0){//see exceptions.md
            throw new IllegalArgumentException("factorial is undefined for negative numbers");
        }
        if(num > 20){//see exceptions.md
            throw new IllegalArgumentException("factorial overflow, please input an integer in the range [0, 20]");
        }
        if(num == 0 || num == 1){
            return 1L;
        }
        return num * factorial(num - 1);
    }
```

### Pass By Value

* `Java` always uses `pass by value` — regardless of whether the data type is a `primitive` or `reference`
* `pass by value` means a **copy of the variable's value** is passed to the method
* `Java` **never** passes the original variable itself
* `pass reference types by value` is **similar to** `pass by reference` (pass its memory address), but **cannot reassign** the caller's reference
* how copying works
    * `primitive types` copy the **actual value**, so changes **do not affect** the original variable
    * `Reference types` copy the **memory address** (`reference`), **not the object itself**, so you **can modify** the object but **cannot reassign** the original reference

#### Example#1: Primitive Types

```java
    public static void main(String [] args){
        int num = 5;
        add5(5);
        System.out.println("after called add5(num), num:\t" + num);//5, instead of 10
    }

    private static void add5(int num){
        num += 5;//cannot affect the original data value
    }
```

#### Example#2: Reference Types

```java
    public static void main(String [] args){
        List <Integer> nums = new ArrayList<>();
        add5(nums);
        System.out.println("after called add5(nums), nums:\t" + nums);//only one 5
    }

    private static void add5(List <Integer> nums){
        nums.add(5);//add 5 to passed address, list nums

        nums = new ArrayList<>(Arrays.asList(1, 2, 3));//reassign nums to a new arraylist address, the address is a new address, instead of passed address
        nums.add(5);//add 5 to the new reassigned address, instead of the passed address
    }
```

### `final parameters`

* prevent **modification inside the method**

#### Example

```java
    public static void main(String [] args){
        add1ThenPrint(3);
        cannotAdd1ThenPrint(3);
    }

    private static void add1ThenPrint(int num){
        num++;
        System.out.println("after adding 1:\t" + num);
    }

    private static void cannotAdd1ThenPrint(final int num){
        //num++;
        System.out.println("cannot add 1:\t" + num);
    }
```
