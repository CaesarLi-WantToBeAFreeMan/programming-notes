## 010. methods

### concepts

* blocks of code that perform a task and are invoked by name
* support `overloading`, `varargs`, and `lambda` expressions
* all arguments are `passed by value` (even **object references**)


### traditional methods

#### definition

```java
    [accessModifier] [static] [returnType] methodName([parameters]){
        //method body
        [return returnedData;]
    }
```

* `[content]` means this part is optional
* `accessModifier`: we'll talk later in `basicOOP.md`
* `static`: we'll talk later in `static.md`
* `returnType`: data type of the method returned
    * types:
        1. `void`: return nothing (`none`)
        2. `non-void`: include `primitive types` (`byte`, `short`, `int`, `long`, `float`, `double`, `char` and `boolean`) and `reference types` (`String`, `ArrayList`, etc)
* `methodName`: name of a method
* `parameters`: input data to the method
* `method body`: statements inside the method
* `return returnedData`: data that should be returned, if the method is `non-void`

#### invocation

```java
    methodName(parameters);
```

* `methodName`: name of a method
* `parameters`: data that should be passed to the method

#### example

1. void method: greet

    ```java
        public class Main{
            public static void main(String [] args){
                greet();
            }

            private static void greet(){
                System.out.println("Hello!!!");
            }
        }
    ```

2. primitive: sum of two `int`s

    ```java
        public class Main{
            public static void main(String [] args){
                System.out.println(getSum(12, 21));
            }

            private static void getSum(int num0, int numn1){
                return num0 + num1;
            }
        }
    ```

3. reference0: greet to a person

                greet("Caesar James LEE");
            }

            private static void greet(String name){

4. reference1: sum of a range from a `ArrayList <int>`

    ```java
        import java.util.Arrays;
        import java.util.ArrayList;
        import java.util.List;

        public class Main{
            public static void main(String [] args){
                List <Integer> nums = new ArrayList(Arrays.asList(12, 21, 0, -5, 3, 9));
                for(int i = 0; i < 12; i++){
                    nums.add(i);
                }
                System.out.println(getSumFrmRange((ArrayList)nums, 3, 9));
            }

            private static void getSumFromRange(ArrayList <Integer> nums, int left, int right){
                int sum = 0;
                for(int i = left; i < right; i++){
                    sum += nums.get(i);
                }
                return sum;
            }
        }
    ```
