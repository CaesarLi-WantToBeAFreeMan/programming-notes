## 001. basic `I/O` (`input or output`)

### output

#### 1. `System.out.println()`

* used to **display something on your console**
* this statement **adds a new line at the end**
* example:

```java
    System.out.println("Hello World!\n" + "By The Way, I'm " + 18 + " years old!");
```

* result
```
    Hello World
    By The Way, I'm 18 years old!

```

#### 2. `System.out.print()`

* like `System.out.println()`
* but **doesn't add a new line at the end**
* example:

```java
    System.out.print("Hello World\n" + "By The Way, I'm " + 18 + " years old!");
```

* result

```
    Hello World
    By The Way, I'm 18 years old!
```

#### 3. `System.out.printf()`

* like `System.out.print()` and `System.out.println()`,
* but let you use a `format string` to control the output format
* format string: `"%[arg$][flags][width][.precision]conversion"`

##### `arg$`

* **optional**
* a number followed by a `$` sign
* useful for **reordering** arguments or **reusing the same argument**
* By default, the number is `1`
* example:

```java
    System.out.printf("I'm %2$d years old, and Lisa is %1$d years old, and Taylor is %2$d years old!\n", 21, 18);
```

* result:

```
    I'm 18 years old, and Lisa is 21 years old, and Taylor is 18 years old!
```

##### `flags`

* **optional**
* modify aligning or add signs
* formats:
    1. `-`: makes the output **left-justified** by **adding spaces to right**, **by default to left**
    2. `+`: forces **positive numbers** to always be prefixed with `+`
    3. ` `(a space): forces **positive numbers** to always be prefixed with ` `(a space)
    4. `(`: encloses **negative numbers** in parentheses
    5. `0`: pads the output with **zeros** until the specified width is reached
    6. `,`: adds a **comma** to group thousands in numbers
    7. `#`: controls a prefix
        * for `o` conversion, it prefixes **`0`**
        * for `x` conversion, it prefixes **`0x`**
        * for `X` conversion, it prefixes **`0X`**
        * for `f` ,`e`, `E`, `g` and `G`, it ensures the **result contains a decimal point**
    * example:

    ```java
        System.out.printf("%-5d\n", 12);
        System.out.printf("%5d\n", 12);
        System.out.printf("%05d\n", 12);
        System.out.printf("%+d\n", 12);
        System.out.printf("% d\n", 12);
        System.out.printf("%(d\n", -12);
        System.out.printf("%,d\n", 123456789);
    ```

    * result

    ```
        12   (3 spaces at the end)
           12(3 spaces at the beginning)
        00012
        +12
         12(a space at the beginning)
        (12)
        123,456,789
    ```

##### `width`

* **optional**
* specify the **minimum number** of characters
* if the actual number is lower, width is ignored
* example:

    ```java
        System.out.printf("%03d", 12);
    ```

* result

    ```
        012
    ```

##### `.precision`

* **optional**
* a dot `.` followed by a number
* control **how many digits** after the decimal are shown
* used for **floating-point number**
* by default, `Java` shows `6 decimal digits`
* example:

```java
    System.out.printf("%.15f\n", Math.PI);
    System.out.printf("%.3f\n", Math.PI);
    System.out.printf("%f\n", Math.PI);
```

* result

```
    3.141592653589793
    3.142
    3.141593
```

##### `conversion`

* **required**
* specifies the data type
* formats:
    1. `%`: display a **`%`**
    2. `n`: display a **line break**
    3. `b`: display a **lowercase boolean**(`false` or `true`)
    4. `B`: display a **uppercase boolean**(`FALSE` or `TRUE`)
    5. `c`: display **a unicode character**
    6. `C`: display **a unicode uppercase character** if applicable
    7. `s`: display **a string**
    8. `S`: display **a uppercase string**
    9. `d`: display **an integer**
    10. `h`: display **a lowercase hexadecimal** (`a-f`)
    11. `H`: display **a uppercase hexadecimal** (`A-F`)
    12. `o`: display **an octal integer**
    13. `x`: display **a lowercase hexadecimal** (`a-f`)
    14. `X`: display **a uppercase hexadecimal** (`A-F`)
    15. `e`: display **lowercase scientific notation** (`e`)
    16. `E`: display **uppercase scientific notation** (`E`)
    17. `f`: display a **floating-point number**
    18. `g`: display the lowercase shortest format
    19. `G`: display the uppercase shortest format
    20. `a`: display **a lowercase hexadecimal floating-point** (`a-f`)
    21. `A`: display **a uppercase hexadecimal floating-point** (`A-F`)

### input

#### `Scanner`

* used to read user input
* found in the `java.util` package

```java
    import java.util.Scanner;
```

* to use it, you should create a `Scanner` object

#### constructors

1. `Scanner(System.in)`: read from console
2. `Scanner("fileNmae.fileType")`: read from a file
3. `Scanner("text")`: read from a specified string

#### methods

1. `nextBoolean()`: read a `boolean`
2. `nextByte()`: read a `byte`
3. `nextDouble()`: read a `double`
4. `nextFloat()`: read a `float`
5. `nextInt()`: read an `int`
6. `nextLine()`: read the whole line as a `string`
7. `nextLong()`: read a `long`
8. `nextShort()`: read a `short`
9. `next()`: read the next token (word), ends with a space (` `) or newline is encountered

#### destructor

1. `close()`: releases system resources used by the `Scanner`

#### `I/O` example

```java
    import java.util.Scanner;

    public class Main{
        public static void main(String [] args){
            Scanner scanner = new Scanner(System.in);
            System.out.print("enter your name:\t");

            String name = scanner.nextLine();
            System.out.print("enter your age:\t");

            int age = scanner.nextInt();
            System.out.print("enter your change:\t");

            double change = scanner.nextDouble();
            System.out.print("enter your gender (M for male F for female):\t");

            char gender = Character.toLowerCase(scanner.next().charAt(0));
            System.out.printf(
                "Hello %s, a %d-year-old %s, and you have %.2f$",
                name,
                age,
                gender == 'm' ? "male" : gender == 'f' ? "female" : "unknown",
                change
            );

            scanner.close();
        }
    }
```

#### `I/O` example explanation

1. `String`: a sequence of characters
2. `int`: an integer
3. `double`: a floating-point
4. `char`: a single  character
5. `Character.toLowerCase(char || int)`: convert a char or an int into lowercase
6. `charAt(index)`: get the character at a given index in a string
