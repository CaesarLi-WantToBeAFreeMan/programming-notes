## 000. Java Info

### Overview

* a **high-level**, **object-oriented**, **platform-independent** language created by `Sun Microsystems`(later acquired by `Oracle`)
* designed to `Write Once, Run Anywhere` (`WORA`) - meaning compiled Java code can run on **any device with a `Java Virtual
  Machine`(`JVM`)

### Compare With `C++`

| property | `C++` | `Java` |
| :-: | :-: | :-: |
| `compilation` | compile to **machine code** | compile to **bytecode** |
| `system independent` | ❌ different machine code across OS | ✔️ by `JVM` |
| `execution` | **directly** by `OS` | by `JVM` |
| `inheritance`  | single and multiple(`virtual`) | single **only**(multiple via `interface`) |
| `pointers` | ✔️ support | ❌ only `references` |
| `memory management` | manual(`new`/`delete`) | automatic(`garbage collector`) |
| `global scope` | ✔️ support | ❌ **not** support |
| `goto` | ✔️ support | ❌ exist but **not** implemented |
| `operator overloading` | support(except `.`,`::`,`.*`,`?:`,`sizeof`) | **not** support |
| `template` | `timeplate`(**compile-time**) | `generics`(**runtime**, **type erasure**) |
| `structs` | ✔️ support | ❌ **not** support(can use `inner class`) |
| `default argument` | ✔️ support | ❌ **not** support |
| `constant` | `const` | `final` |
| `unsigned types` | ✔️ support | ❌ **only** signed |
| `argument passing ways` | `pass by value` and `pass by reference` | **only** `pass by value` |
| `friend functions` | ✔️ support | ❌ **not** support |
| `union` | ✔️ support | ❌ **not** support |
| `access modifies` | `public`, `private`(**default**), `protected` | plus ` `(ignore, **default**) |

### Compilation and Execution Process

```mermaid

    bytecode -- interpreter --> jvmWindows[JVM for Microsoft Windows];
    bytecode -- interpreter --> jvmMac[JVM for macOS];
    bytecode -- interpreter --> jvmLinux[JVM for Linux];
```

### `JDK` Architecture

```mermaid
flowchart TB
    bytecode[.class bytecode file] -- load classes --> loading;

    subgraph loading[<b><i>Class Loader Subsystem</i></b>]
        direction TB;
        loadingDescription(<b>Description</b><br>JVM finds the binary representation of a class and creates it);

        subgraph loaders[ ]
            direction LR;
            bootstrap{{<b>Bootstrap Class Loader</b><br>load core Java classes, e.g. java.lang, java.util<br>written in native code C/C++}};
            extension{{<b>Extension Class Loader</b><br>load extension libraries, e.g. jre/lib/ext<br>child of Bootstrap}};
            application{{<b>Application Class Loader</b><br>load classes from classpath<br>child of Extension}};
            bootstrap ==> extension ==> application;
        end;

        loadingDescription ~~~ loaders;
    end;

    loading --> linking;
    subgraph linking[<b><i>Linking</i></b>]
        direction LR;

        verification{{<b>Verification</b><br>ensure .class bytecode is valid<br>verify structure, bytecode validity<br>check security constraints}};
        preparation{{<b>Preparation</b><br>allocate memory for static variables<br>initialize with default values<br>int = 0, boolean = false, object = null}};
        resolution{{<b>Resolution</b><br>replace references with direct references<br>e.g. replace java/lang/String with actual memory address}};
        verification ==> preparation ==> resolution;
    end;
    
    linking --> initializing{{<b>Initialization</b><br>assign static variables to actual values<br>execute static blocks from top to bottom<br>execute static initializers}}
            --> runtimeDataArea;

    subgraph runtimeDataArea[<b><i>Runtime Data Area</i></b>]
        direction TB;

        runtimeDataDescription(<b>Description</b><br>JVM defines runtime data areas needed during program execution);

        subgraph areas[ ]
            direction LR;
            subgraph shared[<b><i>Shared Among All Threads</i></b>]
                method{{<b>Method Area Heap aka Metaspace in Java 8+</b><br>store class metadata, static variables, constants, method code, field data}};
                heap{{<b>Heap Area</b><br>store objects, arrays<br>divided into Youngh Gen and Old Gen<br>Garbage Collection manages this area}};
                method ~~~ heap;
            end;

            subgraph perThread[<b><i>Per Thread</i></b>]
               stack{{<b>Stack Area</b><br>store local variables, method parameters, partial results, return addresses<br>each method call creates a stack frame}};
                pcRegister{{<b>Program Counter Register</b><br>store address of the JVM instruction<br>each thread has its own PC register}};
                nativeMethodStack{{<b>Native Method Stack</b><br>store native method information used when calling C/C++ methods via JNI<br>like Stack for native code}};
                stack ~~~ pcRegister ~~~ nativeMethodStack;
            end;

            shared ~~~ perThread;
        end;

        runtimeDataDescription ~~~ areas;
    end;

    runtimeDataArea --> executionEngine;

    subgraph executionEngine[<b><i>Execution Engine</i></b>]
        direction TB;

        executionEngineDescription(<b>Description</b><br>responsible for executing bytecode line by line);

        subgraph components[ ]
            direction LR;
            interpreter{{<b>Interpreter</b><br>interprete bytecode<br>slower for repeated code<br>fast startup time}};
            jitCompiler{{<b>Just In Time Compiler</b><br>compile hot code to native machine code<br>improve performance for repeated execution<br>include C1 lightweight and C2 optimizing}}
            garbageCollector{{<b>Garbage Collector</b><br>automatically manage memory<br>remove unreferenced objects from heap<br>algoriths: Serial, Parallel, CMS, G1, ZGC, Shenandoah}};
            profiler{{<b>Profiler</b><br>monitor code execution<br>identify hot spots for JIT compilation}};

            interpreter ~~~ jitCompiler ~~~ garbageCollector ~~~ profiler;
        end;

        executionEngineDescription ~~~ components;
    end;

    executionEngine --> jni{{<b>Java Native Interface</b><br>framework for calling native code<br>allow Java to interact with C/C++ libraries<br>provide two-way communication}}
                    --> nativeMethodLibraries{{<b>Native Method Libraries</b><br>collection of native libraries<br>C/C++ platform implementations<br>e.g. system calls, hardware access}};
```
