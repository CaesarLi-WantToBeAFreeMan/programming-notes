## 007. strings

### `String`

* an object to store a sequence of characters
* can store at most ${2}^{32} - 1$ bytes (about `4.3 gigabytes`) of text content
* once created, **cannot be changed** (`immutable`)
* stored in the `string pool` if declared as a literal (e.g. `"hello"`)
* **most commonly used object** in Java, often optimized internally by the `JVM` (`Java Virtual Machine`)

#### constructors

| constructors                                                          | description                                                                           |
| :-------------------------------------------------------------------: | :-----------------------------------------------------------------------------------: |
| `String()`                                                            | create an empty string `""`                                                           |
| `String(byte [] bytes)`                                               | decode `byte array` using the system's default `charset` (often `UTF-8`)              |
| `String(byte [] bytes, Charset charset)`                              | decode using a specified `Charset` object                                             |
| `String(byte [] bytes, String charsetName)`                           | same as `3`, but charset is passed as a `String` name                                 |
| `String(byte [] bytes, int offset, int length)`                       | decode part of `byte array` from `offset` with `length` bytes using default `charset` |
| `String(byte [] bytes, int offset, int length, Charset charset)`      | decode part of `byte array` using specified `Charset`                                 |
| `String(byte [] bytes, int offset, int length, String charsetName)`   | same as `6`, but charset name is a `String`                                           |
| `String(char [] value)`                                               | build from full `char array`                                                          |
| `String(char [] value, int offset, int count)`                        | build from `char array` in range [offset, offset + count)                             |
| `String(int [] codePoints, int offset, int count)`                    | build from `Unicode code points` codePoints [offset, offset + count)                  |
| `String(String original)`                                             | make a copy of an existing `String`                                                   |
| `String(StringBuffer buffer)`                                         | convert a **thread-safe** `StringBuffer` to a string                                  |
| `String(StringBuilder builder)`                                       | convert a `StringBuilder` to a string                                                 |

* example

```java
    //empty string
    String s1 = new String();
    System.out.println("String():\t" + s1);

    //a byte array with a default charset
    byte [] bytes = "Hello".getBytes();//default charset
    String s2 = new String(bytes);
    System.out.println("String(byte [] bytes):\t" + s2);

    //a byte array with UTF-8 charset
    String s3 = new String(bytes, StandardCharsets.UTF_8);
    System.out.println("String(byte [] bytes, Charset charset):\t" + s3);

    //a byte array with UTF-8 charset
    String s4 = new String(bytes, "UTF-8");
    System.out.println("String(byte [] bytes, String charset):\t" + s4);

    //a byte array in range [1, 1 + 3 == 4]
    String s5 = new String(bytes, 1, 3);
    System.out.println("String(byte [] bytes, int offset, int length):\t" + s5);

    //a byte array in range [1, 4] with UTF-8 charset
    String s6 = new String(bytes, 1, 3, StandardCharsets.UTF_8);
    System.out.println("String(byte [] bytes, int offset, int length, Charset charset):\t" + s6);

    //a byte array in range [1, 4] with UTF-8 charset
    String s7 = new String(bytes, 1, 3, "UTF-8");
    System.out.println("String(byte [] bytes, int offset, int length, String charset):\t" + s7);

    //a char array
    char [] chars = {'J', 'a', 'v', 'a', '!', '!', '!'};
    String s8 = new String(chars);
    System.out.println("String(char [] chars):\t" + s8);

    //a char array in range [1, 4]
    String s9 = new String(chars, 1, 3);
    System.out.println("String(char [] chars, int offset, int count):\t" + s9);

    //an int array in range [0, 4]
    int [] codePoints = {72, 101, 108, 108, 111};//'H', 'e', 'l', 'l', 'o'
    String s10 = new String(codePoints, 0, codePoints.length);
    System.out.println("String(int [] ints, int offset, int length):\t" + s10);

    //a String
    String s11 = new String(s10);
    System.out.println("String(String string):\t" + s11);

    //a StringBuffer
    StringBuffer buffer = new StringBuffer("StringBuffer!");
    String s12 = new String(buffer);
    System.out.println("String(StringBuffer buffer):\t" + s12);

    //a StringBuilder
    StringBuilder builder = new StringBuilder("StringBuilder!");
    String s13 = new String(builder);
    System.out.println("String(StringBuilder builder:\t" + s13);
```

### `StringBuilder`

* used to build or modify strings **efficiently**
* can change content **without creating new objects** (`mutable`)
* **faster** than `String` for repeated modifications
* **not thread-safe** (use `StringBuffer` if needed)

#### constructors

| constructor                       | description                                                   |
| :-------------------------------: | :-----------------------------------------------------------: |
| `StringBuilder()`                 | create empty builder with **default capacity** (`16 chars`)   |
| `StringBuilder(CharSequence seq)` | copy content from any `character sequence`                    |
| `StringBuilder(int capacity)`     | create empty builder with custom `initial capacity`           |
| `StringBuilder(String str)`       | copy content from a `String`                                  |

* example

```java
    //empty string builder(default capacity 16)
    StringBuilder builder0 = new StringBuilder();
    System.out.println("an empty StringBuilder:\t" + builder0);

    //string builder from CharSequence (e.g., StringBuffer, StringBuilder, or String)
    CharSequence charSequence = "Hello";
    StringBuilder builder1 = new StringBuilder(charSequence);
    System.out.println("StringBuilder from a CharSequence:\t" + builder1);

    //string builder with a custom capacity
    StringBuilder builder2 = new StringBuilder(50);
    System.out.println("StringBuilder with capacity of 50:\t" + builder2);

    //string builder from a string
    StringBuilder builder3 = new StringBuilder("World");
    System.out.println("StringBuilder from a string:\t" + builder3);
```

* `String` vs `StringBuilder`

| feature                   | `String`                                                          | `StringBuilder`                                                   |
| :-----------------------: | :---------------------------------------------------------------: | :---------------------------------------------------------------: |
| mutability                | `immutable` (**cannot change** once created)                      | `mutable` (can be **modified in place**)                          |
| thread safety             | `thread-safe` (due to `immutability`)                             | **not** thread-safe                                               |
| performance               | **slower** for many changes (**creates new object**)              | **faster** for frequent updates                                   |
| memory usage              | **create multiple objects**                                       | `efficient` change happen in the **same buffer**                  |
| usage                     | string stays the same<br>in a simple, readable, thread-safe code  | build strings in a loop<br>modify string content frequently       |
| thread-safe alternative   | `String` (safe)                                                   | use `StringBuffer` if **thread safety is needed**                 |

* example

```java
    final int TIMES = 100_000;

    // String test
    long start = System.nanoTime();
    String s = "";
    for(int i = 0; i < TIMES; i++){
        s += "a";
    }
    System.out.println("String time:\t" + (System.nanoTime() - start) / 1_000_000.0 + " ms");

    // StringBuilder test
    start = System.nanoTime();
    StringBuilder stringBuilder = new StringBuilder();
    for(int i = 0; i < TIMES; i++){
        stringBuilder.append("a");
    }
    System.out.println("StringBuilder time:\t" + (System.nanoTime() - start) / 1_000_000.0 + " ms");
```

* sample output on my system

```

    StringBuilder time:	2.2304 ms
```

### `StringBuffer`

* a **mutable** sequence of characters (like `StringBuilder`)
* **thread-safe** (`synchronized`), but **slower** than `StringBuilder` in single-threaded cases
* share the **same API** (same `constructors`, `methods`, etc) with `StringBuilder`
* `StringBuilder` vs `StringBuffer`

| feature       | `StringBuilder`                       | `StringBuffer`                        |
| :-----------: | :-----------------------------------: | :-----------------------------------: |
| thread-safe   | ❌ no                                | ✅ yes (uses `synchronized` methods)  |
| performance   | ✅ faster in `single-threaded` code  | ❌ slower due to `synchronization`    |
| use case      | `single-threaded` string modification | `multi-threaded` environments         |

* example

```java
    final int TIMES = 1_000_000;

    //StringBuilder
    long start = System.nanoTime();
    StringBuilder builder = new StringBuilder();
    for(int i = 0; i < TIMES; i++){
        builder.append("a");
    }
    System.out.println("StringBuilder time:\t" + (System.nanoTime() - start) / 1_000_000.0 + " ms");

    //StringBuffer
    start = System.nanoTime();
    StringBuffer buffer = new StringBuffer();
    for(int i = 0; i < TIMES; i++){
        buffer.append("a");
    }
    System.out.println("StringBuffer time:\t" + (System.nanoTime() - start) / 1_000_000.0 + " ms");
```

* sample output on my system

```
    StringBuilder time:	10.7553 ms
```
