### `Random`

* used to generate **pseudo-random numbers**
* you can create a `Random` object with or without a **seed**

#### Constructors

| constructor | description |
| :-: | :-: |
| `Random()` | create a new random number generator using a random seed, usually current time |
| `Random(long seed)` | create a new random number generator using a single long seed |

#### Methods

##### Value Generation

* `T` stand for `boolean`, `int`, `long`, `float`, `double`

| method | description |
| :-: | :-: |
| `T nextT()` | return a random value of type `T` |
| `int nextInt(int end)` | return random `int` in $[0, \text {end})$ |
| `double nextGaussian()` | return Gaussian (normal) distributes `double` with $\mu = 0$, $\sigma = 1$) |
| `void nextBytes(byte [] bytes)` | fill a byte array with random bytes |

##### Stream Generation

* `T` stand for `int`, `long`, `double`

| method | description |
| :-: | :-: |
| `TStream Ts()` | return a `T` type stream in [0, 1) |
| `TStream Ts(T start, T end)` | return a `T` type stream in [$\text {start}$, $\text {end}$] |
| `TStream Ts(long size)` | return a `T` type stream with a given size in [0, 1) |
| `TStream Ts(long size, T start, T end)` | return a random `T` type stream in [$\text {start}$, $\text {end}$] |

##### Set Seed

| method | description |
| :-: | :-: |
| `void setSeed(long seed)` | set or reset the random sequence using a specific seed |

* example

```java
    import java.util.*;
    import java.util.stream.*;

    public class Main{
        public static void main(String [] args){
            Random random = new Random();

            //basic values
            System.out.println("nextInt():\t" + random.nextInt());
            System.out.println("nextInt(100):\t" + random.nextInt(100));
            System.out.println("nextLong():\t" + random.nextLong());
            System.out.println("nextFloat():\t" + random.nextFloat());
            System.out.println("nextDouble():\t" + random.nextDouble());
            System.out.println("nextBoolean():\t" + random.nextBoolean());
            System.out.println("nextGaussian():\t" + random.nextGaussian());

            //random bytes
            byte [] bytes = new byte [5];
            random.nextBytes(bytes);
            System.out.println("nextBytes():\t" + Arrays.toString(bytes));

            //streams
            System.out.println("3 random ints in [0, 100): " +
                    random.ints(3, 0, 100).boxed().collect(Collectors.toList()));

            System.out.println("3 random longs: " +
                    random.longs(3).boxed().collect(Collectors.toList()));

            System.out.println("3 random doubles in [1.0, 2.0): " +
                    random.doubles(3, 1.0, 2.0).boxed().collect(Collectors.toList()));
        }
    }
```

```java
    import java.math.BigInteger;
    import java.util.Random;

    public class Main{
        public static void main(String [] args){
            //constructors
            byte [] bytes = {1, 2, 3};
            BigInteger bi1 = new BigInteger(bytes);//binary: 010203
            System.out.println("bi1:\t" + bi1);
            BigInteger bi2 = new BigInteger(1, bytes);//from sign and magnitude
            System.out.println("bi2:\t" + bi2);
            BigInteger bi3 = new BigInteger("123456789");//from decimal string
            System.out.println("bi3:\t" + bi3);
            BigInteger bi4 = new BigInteger("FF", 16);//from hex string
            System.out.println("bi4:\t" + bi4);
            BigInteger bi5 = new BigInteger(16, new Random());//random in [0, 2^16)
            System.out.println("bi5:\t" + bi5);
            BigInteger bi6 = new BigInteger(16, 10, new Random());//random probable prime in [0, 2^16)
            System.out.println("bi6:\t" + bi6);

            //fields
            System.out.println("ZERO:\t" + BigInteger.ZERO);
            System.out.println("ONE:\t" + BigInteger.ONE);
            System.out.println("TEN:\t" + BigInteger.TEN);

            //arithmetic methods
            System.out.println("bi1 + bi5:\t" + bi1.add(bi5));                   //bi1 + bi5
            System.out.println("bi1 - bi5:\t" + bi1.subtract(bi5));              //bi1 - bi5
            System.out.println("bi1 * bi5:\t" + bi1.multiply(bi5));              //bi1 * bi5
            System.out.println("bi1 / bi5:\t" + bi1.divide(bi5));                //bi1 ÷ bi5
            System.out.println("bi1 % bi5:\t" + bi1.remainder(bi5));             //bi1 mod bi5

            //modular arithmetic
            System.out.println("bi1 mod bi5:\t" + bi1.mod(bi5));                        //bi1 mod bi5
            System.out.println("bi1^2 mod bi5:\t" + bi1.modPow(BigInteger.TWO, bi5));   //bi1^2 mod bi5
            System.out.println("bi1^(-1) mod m:\t" + bi1.modInverse(BigInteger.TEN));    //bi1^(-1) mod 10

            //bitwise operations
            System.out.println("bi1 & bi5:\t" + bi1.and(bi5));
            System.out.println("bi1 | bi5:\t" + bi1.or(bi5));
            System.out.println("bi1 ^ bi5:\t" + bi1.xor(bi5));
            System.out.println("~bi1:\t" + bi1.not());
            System.out.println("bi1 << 2:\t" + bi1.shiftLeft(2));
            System.out.println("bi1 >> 2:\t" + bi1.shiftRight(2));

            //comparison & checks
            System.out.println("bi1 == bi5:\t" + bi1.equals(bi5));
            System.out.println("bi1 < bi5:\t" + (bi1.compareTo(bi5) < 0));
            System.out.println("bi1 isProbablePrime:\t" + bi1.isProbablePrime(10));

            //other utilities
            System.out.println("bi1.pow(3):\t" + bi1.pow(3));           //bi1^3
            System.out.println("gcd(bi1, bi5):\t" + bi1.gcd(bi5));      //gcd(bi1, bi5)
            System.out.println("abs(bi1):\t" + bi1.abs());              //|bi1|
            System.out.println("negate(bi1):\t" + bi1.negate());        //-bi1
            System.out.println("bitLength:\t" + bi1.bitLength());       //number of bits
            System.out.println("toString:\t" + bi1.toString(16));       //hex string
        }
    }
```

```java
    import java.math.BigDecimal;
    import java.math.MathContext;
    import java.math.RoundingMode;

    public class Main{
        public static void main(String [] args){
            BigDecimal a = new BigDecimal("12.345");
            System.out.println("a:\t" + a);
            BigDecimal b = new BigDecimal("2.5");
            System.out.println("b:\t" + b);
            MathContext mc = new MathContext(3, RoundingMode.HALF_UP);//set precision to 3, and rounding

            //arithmetic
            System.out.println("a + b:\t" + a.add(b));
            System.out.println("a + b(precision: 3, HALF_UP):\t" + a.add(b, mc));
            System.out.println("a - b:\t" + a.subtract(b));
            System.out.println("a - b(precision: 3, HALF_UP):\t" + a.subtract(b, mc));
            System.out.println("a * b:\t" + a.multiply(b));
            System.out.println("a * b(floating-point)(precision: 3, HALF_UP):\t" + a.multiply(b, mc));
            System.out.println("a / b(floating-point)(precision: 4, HALF_UP):\t" + a.divide(b, 4, RoundingMode.HALF_UP));
            System.out.println("a / b(floating-point)(precision: 3, HALF_UP):\t" + a.divide(b, mc));
            System.out.println("a / b(integral):\t" + a.divideToIntegralValue(b));
            System.out.println("a % b:\t" + a.remainder(b));
            BigDecimal [] divRem = a.divideAndRemainder(b);
            System.out.println("quotient:\t" + divRem [0] + ", remainder: " + divRem [1]);
            System.out.println("a^2:\t" + a.pow(2));
            System.out.println("a^2(precision: 3, HALF_UP):\t" + a.pow(2, mc));

            //comparison
            System.out.println("a compareTo b:\t" + a.compareTo(b));
            System.out.println("a equals b:\t" + a.equals(b));
            System.out.println("sign of a:\t" + a.signum());
            System.out.println("minimum:\t" + a.min(b));
            System.out.println("maximum:\t" + a.max(b));
            System.out.println("plus:\t" + a.plus());
            System.out.println("plus(precision: 3, HALF_UP):\t" + a.plus(mc));
            System.out.println("negate:\t" + a.negate());
            System.out.println("negate(precision: 3, HALF_UP):\t" + a.negate(mc));

            //scale & rounding
            System.out.println("scale:\t" + a.scale());//precision
            System.out.println("scaleByPowerTen(2):\t" + a.scaleByPowerOfTen(2));//times 10^2, then set scale to 5
            System.out.println("setScale(2, RoundingMode.DOWN):\t" + a.setScale(2, RoundingMode.DOWN));
            System.out.println("round(precision: 3, HALF_UP):\t" + a.round(mc));
            System.out.println("stripTrailingZeros:\t" + new BigDecimal("12.3400").stripTrailingZeros());

            // Conversion
            System.out.println("toString:\t" + a.toString());
            System.out.println("toPlainString:\t" + a.toPlainString());
            System.out.println("engineering string of 1 million trillion.123 456 789:\t" + BigDecimal.valueOf(1_000_000_000_000_000_000.123_456_789).toEngineeringString());
            System.out.println("toBigInteger:\t" + a.toBigInteger());
            try{
                System.out.println("toBigIntegerExact:\t" + new BigDecimal("10.0").toBigIntegerExact());
            }catch(ArithmeticException e){
                System.out.println("toBigIntegerExact: error");
            }
            System.out.println("unscaledValue:\t" + a.unscaledValue());
            System.out.println("intValue:\t" + a.intValue());
            System.out.println("longValue:\t" + a.longValue());
            System.out.println("floatValue:\t" + a.floatValue());
            System.out.println("doubleValue:\t" + a.doubleValue());

            System.out.println("valueOf(5):\t" + BigDecimal.valueOf(5));
            System.out.println("valueOf(5, 2):\t" + BigDecimal.valueOf(5, 2));
        }
```

### `RoundingMode`

* define strategies for rounding decimal values in `BigDecimal`, `MathContext`, and other numeric operations

#### Package

```java
    import java.math.RoundingMode;
```

#### Enum

| enum constant | description |
| :-: | :-: |
| `UP` | round away from `0` |
| `DOWN` | round toward `0` |
| `CEILING` | round toward $+ \infty$ |
| `FLOOR` | round toward $- \infty$ |
| `HALF_UP` | round to nearest, ties go **away from `0`** |
| `HALF_DOWN` | round to nearest, ties go **toward `0`** |
| `HALF_EVEN` | round to nearest, ties go to **even digit** |
| `UNNECESSARY` | no rounding allowed, throw if necessary |
