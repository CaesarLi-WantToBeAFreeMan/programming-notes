## 014. Lambda($\lambda$)s

* a **short** block of code that takes parameters and returns a value or performs an action
* **similar** to a `method` but `anonymous` (**without a name**)
* introduced in `Java 8` to support `functional programming` (`FP`) and to provide a clear and concise way to represent instances of functional interfaces (interfaces with a `single abstract method`)
* implement functional interfaces `implicitly`
* improve **code readability** and **reduce boilerplate**, especially in `collections` and `event handling`

### Lambda Expression Syntax

1. empty parameter with a statement

    ```java
        () -> statement;
    ```

2. empty parameter with multiple statements

    ```java
        () -> {
            statements;
        }
    ```

3. single parameter with a statement

    ```java
        parameter -> statement;
    ```

4. single parameter with multiple statements

    ```java
        parameter -> {
            parameters;
        }
    ```

5. multiple parameters with a statement

    ```java
        (parameters) -> statement;
    ```

6. multiple parameters with multiple statements

    ```java
        (parameters) -> {
            statements;
        }
    ```

### Functional Interfaces

* an `interface` with **only one** `abstract` method
* provide the `implementation` of the `single abstract method` of a `functional interface`
* these interfaces can have **multiple** `default` or `static` methods, but **only one** `abstract` method

#### Example

* `Greet.java`

    ```java
        public interface Greet{
            void greet(String name);//only abstract method

            default void helloWorld(){//a default method
                System.out.println("Hello,World!");
            }

            static void helloCaesar(){//a static method
                System.out.println("Hello Caesar");
            }
        }
    ```

* `Main.java`

    ```java
        public class Main{
            public static void main(String [] args){
                Greet.helloCaesar();//invoke static method
                Greet greet = name -> System.out.println("Hello " + name);
                greet.helloWorld();//invoke default method
                greet.greet("James");//invoke abstract method
            }
        }
    ```

#### `Java`'s Build-in Functional Interfaces

##### `Consumer`

* take input, return **nothing**

###### Library

```java
    import java.util.function.Consumer;
```

###### Methods

1. `void accept(T t)`
    * perform action on `t`
2. `default Consumer <T> andThen(Consumer <? super T> after)`
    * run another `Consumer` after this one

###### Example

```java
    public class Main{
        public static void main(String [] args){
            Consumer <String> consumer = name -> System.out.print("Hello " + name + "\t"),
                              consumer1 = name -> System.out.println(name.toUpperCase()),
                              consumer2 = consumer.andThen(consumer1);
            consumer2.accept("Caesar");//Hello Caesar   CAESAR
        }
    }
```

###### Other Functional Interfaces

1. `IntConsumer`: `(int value)`
2. `LongConsumer`: `(long value)`
3. `DoubleConsumer`: `(double value)`
4. `BiConsumer`: `(T t, U u)`
5. `ObjIntConsumer`: `(T t, int value)`, no default `andThen`
6. `ObjLongConsumer`: `(T t, long value)`, no default `andThen`
7. `ObjDoubleConsumer`: `(T t, double value)`, no default `andThen`
8. ...

##### Supplier

* take **no input**, return **a result**

###### Library

```java
    import java.util.function.Supplier;
```

###### Methods

1. `T get()`: return a value

###### Example

```java
    import java.time.LocalDateTime;
    import java.time.format.DateTimeFormatter;
    import java.util.function.Supplier;

    public class Main{
        public static void main(String [] args){
            Supplier <LocalDateTime> localDateTimeSupplier = () -> LocalDateTime.now();
            System.out.println(localDateTimeSupplier.get().format(DateTimeFormatter.ofPattern("LLL dd, yyyy\tKK:mm:ss a")));
        }
    }
```

###### Other Functional Interfaces

1. `BooleanSupplier`: `boolean getAsBoolean`
2. `IntSupplier`: `int getAsInt`
3. `LongSupplier`: `long getAsLong`
4. `DoubleSupplier`: `double getAsDouble`

##### `Function`

* take **one input**, return **one output**

###### Library

```java
    import java.util.function.Function;
```

###### Methods

1. `R apply(T t)`: run the function
2. `default <V> Function <T, V> andThen(Function <? super R, ? extends V> after)`: apply another function after
3. `default <V> Function<V, R> compose(Function <? super V, ? extends T> before)`: apply another function before
4. `static <T> Function <T, T> identity()`: return input `as-is`

###### Example

```java
    import java.util.function.Function;

    public class Main{
        public static void main(String [] args){
            Function <String, Integer> stringToLength = words -> words.length();
            Function <Integer, String> lengthToMessage = size -> "size:\t" + size;
            Function <String, String> stringToMessage = stringToLength.andThen(lengthToMessage);
            stringToMessage = stringToMessage.compose(words -> words.toUpperCase());
            System.out.println(Function.identity().apply("Caesar") + "'s " + stringToMessage.apply("Caesar"));
        }
    }
```

###### Other Functional Interfaces

1. `IntFunction`: `int value`
2. `IntToLongFunction`: `long applyAsLong`
3. `IntToDoubleFunction`: `double applyAsDouble`
4. `ToIntFunction`: `int applyAsInt`
5. `LongFunction`: `long value`
6. `LongToIntFunction`: `int applyAsInt`
7. `LongToDoubleFunction`: `double applyAsDouble`
8. `ToLongFunction`: `long applyAsLong`
9. `DoubleFunction`: `double value`
10. `DoubleToIntFunction`: `int applyAsInt`
11. `DoubleToLongFunction`: `long applyAsLong`
12. `ToDoubleFunction`: `double applyAsDouble`
13. `BiFunction`:: `T t, U u, V v`
14. `ToIntBiFunction`: `int applyAsInt`
15. `ToLongBiFunction`: `long applyAsLong`
16. `ToDoubleBiFunction`: `double applyAsDouble`

##### `Predicate`

* evaluate a `condition` and return a `boolean`

###### Library

```java
    import java.util.function.Predicate;
```

###### Methods

1. `boolean test(T t)`: check condition
2. `default Predicate <T> and(Predicate <? super T> other)`: combine conditions using `LOGIC AND`
3. `default Predicate <T> or(Predicate <? super T> other)`: combine conditions using `LOGIC OR`
4. `static <T> Predicate <T> isEqual(Object targetRef)`: check if equals to `x`
5. `default Predicate <T> negate()`: reverse result

###### Example

```java
    import java.util.function.Predicate;

    public class Main{
        public static void main(String [] args){
            Predicate <Integer> isEven = number -> number % 2 == 0,
                                isOdd = number -> number % 2 != 0,
                                isZero = number -> number == 0;
            System.out.println("is three even:\t" + isEven.test(3));
            System.out.println("is three both even and odd:\t" + isEven.and(isOdd).test(3));
            System.out.println("is three either even or odd:\t" + isEven.or(isOdd).test(3));
            System.out.println("is three not equals zero:\t" + isZero.negate().test(3));
            System.out.println("is 3 equals 5:\t" + Predicate.isEqual(3).test(5));
        }
    }
```

###### Other Functional Interfaces

1. `BiPredicate`: `T t, U u`
2. `IntPredicate`: `int value`
3. `LongPredicate`: `long value`
4. `DoublePredicate`: `double value`

##### `Consumer` vs `Supplier` vs `Function` vs `Predicate`

| interface | input | output | purpose | use case |
| :-: | :-: | :-: | :-: | :-: |
| `Consumer` | ✅ (`T`) | ❌ | perform an action on input | print or save something |
| `Supplier` | ❌ | ✅ (`T`) | provide a value with no input | generate a random ID |
| `Function` | ✅ (`T`) | ✅ (`R`) | transform input into output | convert string to length |
| `Predicate` | ✅ (`T`) | ✅ (`boolean`) | test a condition on input | check if number is even |

### Throw an Exception

#### Syntax

* `functional interface`

    ```java
        interface InterfaceName{
            returnType methodName([parameters]) throw ExceptionName;
        }
    ```

* `instantiate`

    ```java
        InterfaceName objectName = ([parameters]) -> {
            if(condition){
                throw new ExceptionName("message");
            }
            [return data;]
        };
        try{
            objectName.methodName([parameter]);
            //statements;
        }catch(ExceptionName e){
            //statements;
        }
    ```

#### Example

* `AgeException.java`

    ```java
        public class AgeException extends RuntimeException{
            public AgeException(String message){
                super(message);
            }
        }
    ```

* `AgeCheck.java`

    ```java
        public interface AgeCheck{
            boolean ageCheck(int age) throws AgeException;
            static final int FEDERALALCOHOLAGELIMIT = 21;
            static final int FEDERALTOBACCOAGELIMIT = 21;
            static final int FEDERALVOTINGAGELIMIT = 18;
            static final int FEDERALMILITARYENLISTMENTAGELIMIT = 17;
            static final int FEDERALHANDGUNAGELIMIT = 21;
            static final int FEDERALLONGGUNAGELIMIT = 18;
            static final int FEDERALMARRIAGEWITHOUTPARENTALCONSENTAGELIMIT = 18;
            static final int FEDERALJURYAGELIMIT = 18;
            static final int FEDERALCOMMERCIALDRIVERSLICENSEAGELIMIT = 21;
            static final int FEDERALLOTTERYAGELIMIT = 18;
        }
    ```

* `Main.java`

    ```java
        import java.util.ArrayList;
        import java.util.List;
        import java.util.Scanner;

        public class Main{
            public static void main(String [] args){
                List <AgeCheck> ageCheckers = new ArrayList<>();
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALALCOHOLAGELIMIT){
                        throw new AgeException("Sorry, we cannot sale you alcohol");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALTOBACCOAGELIMIT){
                        throw new AgeException("Sorry, we cannot sale you tobacco");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALVOTINGAGELIMIT){
                        throw new AgeException("Sorry, you cannot vote");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALMILITARYENLISTMENTAGELIMIT){
                        throw new AgeException("Sorry, you cannot join the army");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALHANDGUNAGELIMIT){
                        throw new AgeException("Sorry, we cannot sale you hand guns");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALLONGGUNAGELIMIT){
                        throw new AgeException("Sorry, we cannot sale you long guns");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALMARRIAGEWITHOUTPARENTALCONSENTAGELIMIT){
                        throw new AgeException("Sorry, you cannot marriage without parental consent");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALJURYAGELIMIT){
                        throw new AgeException("Sorry, you cannot be a jury");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALCOMMERCIALDRIVERSLICENSEAGELIMIT){
                        throw new AgeException("Sorry, you cannot have a commercial driver's license");
                    }
                    return true;
                });
                ageCheckers.add(age -> {
                    if(age < AgeCheck.FEDERALLOTTERYAGELIMIT){
                        throw new AgeException("Sorry, we cannot sale you lottery");
                    }
                    return true;
                });

                Scanner scanner = new Scanner(System.in);
                System.out.println("please enter your age:");
                int age = scanner.nextInt();

                try{
                    if(ageCheckers.forEach(checker -> checker.ageCheck(age))){
                        System.out.println("you can do everything what you want legally");
                    }
                }catch(AgeException e){
                    System.out.println("please grow up");
                    e.printStackTrace();
                }finally{
                    scanner.close();
                }
            }
        }
    ```
