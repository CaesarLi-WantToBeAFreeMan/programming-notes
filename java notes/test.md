## 一、填空

1. 由曲线 $y = x^2 - x + 1$ 和 $x$ 轴、$x = 0$ 和 $x = 1$ 围成的平面图形面积用定积分表示为 _____。由曲线 $y = x^2 - 1$ 和 $x$ 轴围成的平面图形面积用定积分表示为 _____。
2. 若 $x^2 \ln(x)$ 是 $f(x)$ 的一个原函数，则 $\int_1^2 f(x)$。若 $\ln(x) + 3$ 是 $f(x)$ 的一个原函数，则 $\int_2^4 f(x)$ _____。
3. 已知 $\int_1^2 f(x) = 3$，$\int_5^2 f(x) = 4$，则 $\int_1^5 f(x)$ = _____。已知 $\int_2^0 f(x) = -2$，$\int_{-1}^0 f(x) = 5$，则 $\int_{-1}^2 f(x)$ = _____。
4. 已知
$
f(x) =
\begin {cases}
2x + 1, \quad -2 \leq x < 0\\
e^x, \quad 0 \leq x \leq 1
\end {cases}
$
，则 $\int_{-1}^2 f(x)$ = _____。
已知
$
f(x) =
\begin {cases}
\sin(x), \quad - \pi \leq x < 0\\
\sqrt {x}, \quad 0 \leq x \leq \pi
\end {cases}
$
，则 $\int_{-\pi}^{\pi} = f(x)$ = _____。
5. 函数 $y = \frac {1} {x}$ 在区间 $[2, 4]$ 上的平均值等于 _____。函数 $y = \sin(x)$ 在区间 $[0, \pi]$ 上的平均值等于 _____。
6. $\int_{-2}^5 dx$ = _____，$\int_3^3 e^x \sin(x) dx$ = _____，$\int_0^1 \sqrt {1 - x^2} dx$ = _____，$\int_0^3 \lvert x - 1 \rvert dx$ = _____，$\int_{-1}^3 \lvert x \rvert dx$ = _____，$\int_1^{+ \infty} \frac {1} {x \sqrt {x}} dx$ = _____，$\int_1^{+ \infty} \frac {1} {1 + x^2} dx$ = _____，$\int_0^2 e^{2x} dx$ = _____，$\int_0^1 (2x - 1)^2 dx$ = _____。
