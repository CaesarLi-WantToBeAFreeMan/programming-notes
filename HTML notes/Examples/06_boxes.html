HTML

Introduction

HTML (HyperText Markup Language) is the standard markup language used to create webpages. It describes the structure of web documents using tags and elements.

History

1993 — HTML 1.0 Released: The first version of HTML was introduced by Tim Berners-Lee as a means to share documents via the Internet.

1995 — HTML 2.0 Standardized: It became an official standard and gained more structured tags.

2014 — HTML5 Finalized: Introduced new semantic elements, video/audio support, and offline features.

CSS

Introduction

CSS (Cascading Style Sheets) is used to control the layout and appearance of HTML elements. It allows you to style your web pages efficiently and consistently.

History

1996 — CSS1 Introduced: Provided basic style control like fonts, colors, and spacing.

1998 — CSS2 Released: Added support for positioning, z-index, and media types.

2011+ — CSS3 Modularization: Introduced features like animations, transitions, flexbox, and grid layouts.

JavaScript

Introduction

JavaScript is a scripting language used to create dynamic and interactive effects within web browsers. It works alongside HTML and CSS to enhance the user experience.

History

1995 — JavaScript Created: Originally named Mocha, then renamed to LiveScript, and finally JavaScript.

1997 — Standardized as ECMAScript: JavaScript was standardized by ECMA International as ECMAScript.

2009 — Node.js Released: Enabled JavaScript to run on servers, expanding its use cases beyond the browser.
