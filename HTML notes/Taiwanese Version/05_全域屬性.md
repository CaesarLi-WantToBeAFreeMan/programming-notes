# 標題：05 全域屬性

# 作者：李克獨（CJL）

## 全域屬性（Global Attributes）

* 可以套用在任何 HTML 元素上
* 用來控制行為、無障礙存取、樣式，以及 JavaScript 的互動

## `id` 唯一識別碼 (Unique Identifier)

* 為 HTML 元素指定一個唯一的識別碼
* 在整份 HTML 文件中必須 **唯一**
* 常與 CSS（用來套用樣式）、JavaScript（用來互動）與錨點連結一起使用
* 是最 **重要** 的全域屬性之一
* 範例：
```html
    <p id = "topic-1">主題 1</p>
    <a href = "#topic-1">跳至主題 1</a>
    <div id = "container">
        <!-- 可以用 CSS 設計樣式，或用 JavaScript 操作內容 -->
    </div>
```

## `class` - 類別名稱（Class Name）

* 為元素指定一個或多個類別名稱
* 用在 CSS 和 JavaScript 中以設定樣式或行為
* 也是一個 **關鍵** 的全域屬性
* 通常用來讓 CSS 鎖定元素
* 範例：
```html
    <p class = "descriptions highlights">內容</p>
```

## `accesskey` - 鍵盤快速鍵

* 定義一個快捷鍵（通常是一個英文字母或數字），讓使用者快速跳到或選取某個元素
* 為了避免 **衝突**，各瀏覽器要求搭配修飾鍵使用
* 各瀏覽器快捷鍵對照表：

| 瀏覽器                | 快捷鍵組合                     |
| :-------------------: | :---------------------------: |
| Google Chrome         | `alt` + accesskey             |
| Microsoft Edge        | `alt` + accesskey             |
| Apple Safari          | `alt` + accesskey             |
| Opera (v15+)          | `alt` + accesskey             |
| Opera (舊版 v15 前)   | `shift` + `esc` + accesskey   |
| Mozilla Firefox       | `alt` + `shift` + accesskey   |

* 注意：**通常不建議使用 accesskey**
    1. 不同國際鍵盤配置會影響按鍵可用性
    2. 容易與瀏覽器或作業系統快捷鍵衝突
* 範例：
```html
    <a href = "https://www.google.com/" target = "_blank" accesskey = "g">造訪 Google</a>
```

## `contenteditable` - 可編輯內容

* 指定某個元素中的內容是否可以由使用者編輯
* 可選的值：
    1. `true`
    2. `false`（預設值）
* 範例：
```html
    <p contenteditable = "true">你可以編輯這段文字</p>
    <p>這段不能編輯</p>
```

## `hidden` - 隱藏元素

* 讓某個元素不在頁面中顯示
* 範例：
```html
    <p>這段是可見的文字</p>
    <p hidden>這段是被隱藏的文字</p>
```

## `style` - 行內 CSS 樣式

* 直接在元素中套用 CSS 樣式
* 注意：大型專案建議使用 **外部** 或 **內部** CSS
* **請參考 CSS 筆記**
* 範例：
```html
    <div style = "background-color: black;">
        <p style = "font-size: 30px; color: red; font-weight: lighter; text-align: center;">樣式文字</p>
    </div>
```

## `title` - 提示文字（滑鼠懸停時顯示）

* 設定當滑鼠移到元素上方時要顯示的提示文字
* 範例：
```html
    <a href = "https://www.google.com/" target = "_blank" title = "造訪 Google">造訪 Google</a>
```

## `draggable` - 使元素可拖曳

* 指定元素是否可以被拖曳
* 預設情況下，圖片和鏈接是可以拖曳的
* 注意：**要實現完整的拖放功能，您需要使用 JavaScript**
* 示例：[05_globalAttributes.html](../Examples/05_globalAttributes.html)
* 範例
```html
    <p id = "draggable-paragraph" draggable = "true" ondragstart = "drag(event)">可拖曳的文字</p>
    <p ondragstart = "drag(event)">另一個不可拖曳的文字</p>
```

## `inert` - 禁用所有互動

* 禁用元素及其所有子元素的使用者互動和焦點
* 內容仍可見，但完全無功能（例如：無法點擊、輸入等）
* 被螢幕閱讀器和其他輔助工具忽略
* 範例
```html
    <div inert>
        <p>你仍然可以看到我</p>
        <button>你無法點擊我</p>
    </div>
```

## `dir` - 設定文本方向

* 控制元素內文本的方向
* 值
    1. `ltr` (`預設`)
        * 從左到右
    2. `rtl`
        * 從右到左
    3. `auto`
        * 瀏覽器根據內容自動判斷方向
* 範例
```html
    <p lang = "en" dir = "rtl">hello</p>
    <p lang = "zh-hant" dir = "rtl">你好</p>
```

## `spellcheck` - 啟用或禁用拼字檢查

* 啟用瀏覽器對某些元素的拼字檢查
* 適用於：
    1. `<input>`（除了 `type = "password"`）
    2. `<textarea>`
    3. 任何設置 `contenteditable = "true"` 的元素
* 範例
```html
    <p lang = "en" spellcheck = "true">dont sho a mstak sugestion</p>
    <p lang = "en" contenteditable = "true" spellcheck = "true">sho a mstak sugestion</p>
```

## `enterkeyhint`- 虛擬鍵盤「Enter」鍵標籤

* 對 **移動裝置** 非常有用
* 控制虛擬鍵盤上「Enter」鍵的標籤
* 值
    1. `done`
    2. `enter` (`預設`)
    3. `go`
    4. `next`
    5. `previous`
    6. `search`
    7. `send`
* 範例
```html
    <p contenteditable = "true">預設 enter</p>
    <p contenteditable = "true" enterkeyhint = "done">虛擬鍵盤 enter 鍵變為 done</p>
    <p contenteditable = "true" enterkeyhint = "go">虛擬鍵盤 enter 鍵變為 go</p>
    <p contenteditable = "true" enterkeyhint = "next">虛擬鍵盤 enter 鍵變為 next</p>
    <p contenteditable = "true" enterkeyhint = "previous">虛擬鍵盤 enter 鍵變為 previous</p>
    <p contenteditable = "true" enterkeyhint = "search">虛擬鍵盤 enter 鍵變為 search</p>
    <p contenteditable = "true" enterkeyhint = "send">虛擬鍵盤 enter 鍵變為 send</p>
```

## `inputmode` - 虛擬鍵盤類型提示

* 建議在觸控設備上顯示的虛擬鍵盤類型
* 非常有助於提升移動裝置的 **可用性**
* 值
    1. `decimal`
    2. `email`
    3. `none`
        * 不顯示虛擬鍵盤
    4. `numeric`
    5. `search`
    6. `tel`
    7. `text` (`預設`)
    8. `url`
* 範例
```html
    <p contenteditable = "true" inputmode = "decimal">小數鍵盤</p>
    <p contenteditable = "true" inputmode = "email">電子郵件鍵盤</p>
    <p contenteditable = "true" inputmode = "none">無鍵盤</p>
    <p contenteditable = "true" inputmode = "numeric">數字鍵盤</p>
    <p contenteditable = "true" inputmode = "search">搜尋鍵盤</p>
    <p contenteditable = "true" inputmode = "tel">電話鍵盤</p>
    <p contenteditable = "true" inputmode = "url">URL 鍵盤</p>
```

## `popover` – 內建彈出行為

* 使元素像浮動的彈出視窗一樣行為
* 無需 JavaScript 來開啟/關閉
* 在 `Mozilla Firefox` 中不支援
* 使用 `popovertarget` 來參照彈出視窗的 id
* 範例
```html
    <p popover id = "popover-text">一段彈出視窗的文字</p>
    <button popovertarget = "popover-text">切換彈出視窗文字</p>
```

## `tabindex` - 設定標籤順序

* 控制可聚焦元素的鍵盤 Tab 順序
* 從 1 開始（數字越小，先獲得焦點）
* 除非需要精確控制，否則不常使用
```html
    <h2>2025年3月的前六大搜尋引擎</h2>
    <p><a href = "https://www.google.com/" target = "_blank" tabindex = "1">Google</a>: 89.74%，美國</p>
    <p><a href = "https://www.bing.com/" target = "_blank" tabindex = "2">Bing</a>: 4.00%，美國</p>
    <p><a href = "https://yandex.com/" target = "_blank" tabindex = "5">YANDEX</a>: 2.49%，俄羅斯</p>
    <p><a href = "https://www.yahoo.com/" target = "_blank" tabindex = "3">Yahoo!</a>: 1.33%，美國</p>
    <p><a href = "https://duckduckgo.com/" target = "_blank" tabindex = "4">DuckDuckGo</a>0.79%，美國</p>
    <p><a href = "https://www.baidu.com/" target = "_blank" tabindex = "6">Baidu</a>: 0.62%，中國</p>
```

## `data-*` - 存儲自訂資料

* 允許您直接在 HTML 元素中儲存額外資訊
* 資料對頁面/應用程式是私有的，並不會在重新整理後保存
* 非常靈活，適用於臨時或每頁資料
* 範例
```html
    <p id = "user" data-username = "caesar">Caesar</p>
    <script>
        const user = document.querySelector("#user");
        console.log(`username:\t${user.dataset.username}`);
        //按 F12 或右鍵檢查來開啟開發者工具 → 控制台查看結果
    </script>
```
