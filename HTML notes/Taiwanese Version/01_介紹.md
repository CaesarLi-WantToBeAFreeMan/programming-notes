## 什麼是 `HTML`

* `HTML`（HyperText Markup Language，超文字標記語言）是網頁瀏覽器用來顯示網頁內容的標準標記語言  
* 它定義了網頁的內容與結構  
* 用語意化的方式描述網頁的結構，最初也包含一些外觀的提示  

## `HTML` 的歷史

1. 1989 - **網路的概念誕生**
   * `Tim Berners-Lee`（在歐洲核子研究中心 CERN）提出一套用超文字分享文件的系統
2. 1991 - **`HTML 1.0`**
   * `Tim Berners-Lee` 建立了第一版 HTML  
   * 功能非常基礎：標題、段落、清單與連結
3. 1995 - **`HTML 2.0`**
   * 由 `IETF`（網際網路工程任務小組）制定標準  
   * 加入表單等基本元素，結構更完整
4. 1997 - **`HTML 3.2`**
   * 由 `W3C`（萬維網協會）發佈  
   * 新增表格、JavaScript 腳本、樣式（透過 `<style>`）
5. 1999 - **`HTML 4.01`**
   * 廣泛使用的版本  
   * 引入三種版本：`Strict`（嚴格）、`Transitional`（過渡）與 `Frameset`（框架）  
   * 結構更清晰，支援 `CSS` 樣式
6. 2008 - **開始制定 `HTML5` 草案**
   * `W3C` 與 `WHATWG`（網頁超文字應用技術工作小組）開始共同制定新的、支援多媒體的 HTML 標準
7. 2014 - **`HTML5` 正式發佈**
   * 重大更新：支援音訊、影片、畫布（canvas）、SVG、localStorage、本地儲存與語意化標籤（如 `<article>`、`<section>` 等）  
   * 讓 HTML 更適合用來開發應用程式與豐富內容的網站

## 基本概念

### 1. 元素（Element）
* 定義在網頁上顯示的內容與行為的完整結構  
* 通常由起始標籤、內容與結束標籤組成，也可能是自關閉的標籤  
* 範例
```html
    <!--由起始標籤、內容與結束標籤構成的元素-->
    <h1>標題</h1>
    <!--由自關閉標籤構成的元素-->
    <hr>
    <!--使用自關閉標籤並附加屬性的元素-->
    <img src="example.png" alt="範例圖片" title="範例圖片">
```

### 2. 標籤（Tag）
* HTML 中的「標記」語法，告訴瀏覽器你要建立哪種元素
* 分為兩種類型：
    1. 非自關閉的標籤（需要成對）
        * 起始標籤
            * 開啟元素
            * 範例
            ```html
                <div>
            ```
        * 結束標籤
            * 結束元素
            * 範例
            ```html
                </div>
            ```
    2. 自關閉的標籤（單一標籤即可）
        * 同時完成開啟與結束的功能
            * 範例
            ```html
                <!--HTML5 樣式-->
                <hr>
                <!--舊式樣式-->
                <hr />
            ```
* 範例說明
    * 非自關閉元素
    ```
        <div>這是一個容器</div> --- 元素
          |        |       |
          |        |       |
          |        |       |
        起始標籤  內容   結束標籤
    ```
    * 自關閉元素
    ```
        <hr> --- 元素
         |
         |
         |
        自關閉標籤
    ```

### 3. 屬性（Attribute）
* 寫在起始標籤或自關閉標籤內，用來設定這個元素的屬性或行為  
* 格式永遠是：`name = "value"`  
* 範例
    ```html
        <a href = "https://www.google.com" target = "_blank" title = "造訪 Google">
            造訪 Google
        </a>
    ```
    ```
        <a href = "https://www.google.com" target = "_blank" title = "造訪 Google"> --- 元素
         |                                   |          |
         |                                   |          |
         |                                   |          |
        起始標籤                           屬性名稱     屬性值
            造訪 Google --- 內容
        </a> --- 結束標籤
    ```

## 第一個 HTML 頁面

* HTML 原始碼
```html
    <!DOCTYPE html>
    <html>
        <head>
            <title>第一個 HTML 頁面</title>
        </head>
        <body>
            <h1>Hello World!</h1>
        </body>
    </html>
```
* 解釋
    1. `<!DOCTYPE html>`
        * 宣告這是一份 `HTML5` 文件
    2. `<html></html>`
        * 整份文件的根元素
    3. `<head></head>`
        * 置「`詮釋資料`」（關於文件的資訊），**這些內容不會顯示在網頁上**
        * 通常可以設定標題、作者、描述、資料集、圖示 等等
    4. `<title>The First HTML Page</title>`
        * 設定這份文件的標題為「`第一個 HTML 頁面`」
    5. `<body></body>`
        * 放置所有會顯示在網頁上的內容
    6. `<h1>Hello World!</h1>`
        * 在頁面上顯示一個最大的標題
