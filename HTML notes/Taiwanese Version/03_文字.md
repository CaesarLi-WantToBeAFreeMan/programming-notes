# 標題：03 文字元素

# 作者：李克獨（CJL）

## `<h1></h1>` 到 `<h6></h6>` - 標題

* **非自關閉** 標籤  
* 用來定義 HTML 標題  
* 一共有 6 級標題
  * `<h1>` 是最重要的  
  * `<h6>` 是最不重要的  
* ***注意事項***  
  * 每個頁面只使用一個 `<h1>`，有助於無障礙設計和 SEO
  * 不要跳過標題等級
* 範例
```html
    <h1>標題 #1</h1>

    <h2>標題 #2</h2>
    <h2>標題 #2</h2>

    <h3>標題 #3</h3>
    <h3>標題 #3</h3>

    <h4>標題 #4</h4>
    <h4>標題 #4</h4>

    <h5>標題 #5</h5>
    <h5>標題 #5</h5>

    <h6>標題 #6</h6>
    <h6>標題 #6</h6>
```

## `<p></p>` - 段落

* **非自關閉** 標籤
* 定義一個段落
* 瀏覽器會自動在段落前後加上間距
* 範例
```html
    <p>lorem100</p>
```

## `<pre></pre>` - 預格式化文字

* **非自關閉** 標籤
* 保留空白與換行格式
* 適合用來顯示程式碼或特定排版的文字
* 範例
```html
    <pre>
        lorem
        100
    </pre>
```

## `<br>` - 換行

* **自關閉** 標籤
* 在文字中插入換行
* 範例
```html
    <p>
        第1行<br>
        第2行<br>
        第3行
    </p>
```

## `<wbr>` - 斷行機會

* **自關閉** 標籤
* 建議在文字中標註一個位置，讓瀏覽器可以在該位置將長單字換行到下一行
* 範例
```html
    <p>
        verylonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglonglongword<wbr>hi
    </p>
```

## `<hr>` - 水平線

* **自關閉** 標籤
* 插入一條水平線，用來分隔區塊
* 範例
```html
    <p>
        主題#1
        <hr>
        主題#2
    </p>
```

## `<strong></strong>` - 強調重要性

* **非自關閉** 標籤
* 標示重要文字（通常為 **粗體**）
* 範例
```html
    <p>
        <strong>重要</strong>
        資訊
    </p>
```

## `<b></b>` - 粗體（無語意強調）

* **非自關閉** 標籤
* 將文字設為 **粗體**，但不表示語意上的重要
* 範例
```html
    <p>
        <b>粗體</b>
        文字
    </p>
```

## `<em></em>` - 加強語氣

* **非自關閉** 標籤
* 表示強調（通常為 *斜體*）
* 範例
```html
    <p>
        <strong>重要</strong>
        資訊
    </p>
```

## `<i></i>` - 斜體（無語意強調）

* **非自關閉** 標籤
* 僅改變外觀為 *斜體*，無語意
* 範例
```html
    <p>
        <i>斜體</i>
        文字
    </p>
```

## `<mark></mark>` - 高亮文字

* **非自關閉** 標籤
* 用黃色背景標示文字
* 範例
```html
    <p>
        <mark>高亮</mark>
        文字
    </p>
```

## `<small></small>` - 小字

* **非自關閉** 標籤
* 顯示較小的文字
* 範例
```html
    <p>
        價格：$1
        <small>99</small>
    </p>
```

## `<q></q>` - 行內引號

* **非自關閉** 標籤
* 自動加上引號
* 範例
```html
    <p>
        神說：
        <q>要有光。</q>
        就有了光。
    </p>
```

## `<blockquote></blockquote>` - 區塊引用

* **非自關閉** 標籤
* 顯示長段落引用，通常會縮排
* 範例
```html
    <p>
        創世記 1:3<br>
        <blockquote>
            神說：
            <q>要有光。</q>
            就有了光。
        </blockquote>
    </p>
```

## `<cite></cite>` - 引用來源

* **非自關閉** 標籤
* 用於作品標題（預設為 *斜體*）
* 範例
```html
    <p>
        <cite>創世記 1:3</cite>
        <blockquote>
            神說：
            <q>要有光。</q>
            就有了光。
        </blockquote>
    </p>
```

## `<sup></sup>` - 上標文字

* **非自關閉** 標籤
* 將文字上移（例如指數）
* 範例
```html
    <p>
        平方：x<sup>2</sup> = x * x
    </p>
```

## `<sub></sub>` - 下標文字

* **非自關閉** 標籤
* 將文字下移（例如化學式）
* 範例
```html
    <p>
        水：H<sub>2</sub>O
    </p>
```

## `<abbr></abbr>` - 縮寫

* **非自關閉** 標籤
* 使用 `title` 屬性，在滑鼠懸停時顯示全名
* 範例
```html
    <p>
        <abbr title = "美利堅合眾國">美國</abbr> 在 1776 年 7 月 4 日宣告獨立。
    </p>
```

## `<dfn></dfn>` - 定義術語

* **非自關閉** 標籤
* 用來標示在句子或段落中正在被定義的術語
* 在大多數瀏覽器中通常會以斜體顯示
* 有助於螢幕閱讀器和語意工具理解這是定義
* 範例
```html
    <p>
        <dfn>美國</dfn> 是位於北美的國家
    </p>
```

## `<del></del>` - 刪除文字

* **非自關閉** 標籤
* 表示已刪除的文字（通常加上刪除線）
* 範例
```html
    <p>
        <del>已刪除</del> 的文字
    </p>
```

## `<s></s>` - 刪除線文字 (無語意意圖)

* **非自關閉** 標籤
* 以刪除線（像是橫線穿過文字）呈現文字
* 用來表示不準確或不再相關的內容，但不帶有語意強調
* 範例
```html
    <p>
        <s>刪除線</s> 文字
    </p>
```

## `<ins></ins>` - 插入文字

* **非自關閉** 標籤
* 表示新加入的文字（通常為底線）
* 範例
```html
    <p>
        <ins>新增</ins> 的文字
    </p>
```

## `<u></u>` - 底線文字 (無語意意圖)

* **非自關閉** 標籤
* 以底線呈現文字
* 不帶有語意意圖
* 範例
```html
    <p>
        <u>底線</u> 文字
```

## `<code></code>` - 行內程式碼

* **非自關閉** 標籤
* 使用等寬字體顯示程式碼
* 範例
```html
    <p>
        <code>
            <h1>Hello World</h1>
        </code>
    </p>
```

## `<kbd></kbd>` - 鍵盤輸入

* **非自關閉** 標籤
* 表示鍵盤輸入內容
* 範例
```html
    <p>
        <kbd>Ctrl + V</kbd> 用來貼上（Windows）

```

## `<samp></samp>` - 範例輸出

* **非自關閉** 標籤
* 顯示電腦程式的輸出結果
* 範例
```html
    <p>
        1 + 1 = <samp>2</samp>
```

## `<var></var>` - 變數

* **非自關閉** 標籤
* 表示數學或程式中的變數
* 範例
```html
    <p>
        <var>x</var> = 1/2
    </p>
```

## `<ruby></ruby>` - 注音標註（Ruby）

* **非自關閉** 標籤
* 用來標示拼音、注音或註解

## `<rt></rt>` - 注音文字（Ruby Text）

* **非自關閉** 標籤
* 顯示發音或意思

## `<rp></rp>` - 括號註記

* **非自關閉** 標籤
* 提供不支援 `<ruby>` 的瀏覽器可讀內容
* 範例
```html
    <ruby>
        臺
        <rp>(</rp>
        <rt>ㄊㄞˊ</rt>
        <rp>)</rp>
    </ruby>
    <ruby>
        灣
        <rp>(</rp>
        <rt>ㄨㄢ</rt>
        <rp>)</rp>
    </ruby>
    <ruby>
        Taiwan
        <rp>(</rp>
        <rt>tɑɪˈwɑn</rt>
        <rp>)</rp>
    </ruby>
```

## `<bdi></bdi>` - 雙向隔離

* **非自關閉** 標籤
* 用來隔離可能有不同文字方向的文本
* 有助於避免當混合從左到右（LTR，例如中文、英文等）和從右到左（RTL，例如阿拉伯文、希伯來文等）語言時出現的佈局問題
* 瀏覽器會自動偵測 `<bdi></bdi>` 內部內容的方向
* `Apple Safari` 不支援
* 範例
```html
    <p>username: <bdi>Caesar</bdi> 18 years old</p> <!--LTR 英文-->
    <p>username: <bdi>克獨</bdi> 18 years old</p> <!--LTR 中文-->
    <p>username: <bdi>أحمد</bdi> 18 years old</p> <!--RTL 阿拉伯文-->
    <p>username: <bdi>דניאל</bdi> 18 years old</p> <!--RTL 希伯來文-->
```

## `<bdo></bdo>` - 雙向覆蓋

* **非自關閉** 標籤
* 用來強制指定文字的方向，覆蓋瀏覽器的預設或自然方向
* 必須使用 `dir` 屬性，並賦予以下值：
    1. `ltr` 從左到右
    2. `rtl` 從右到左
* 範例
```html
    <p>正常：1234 السلام</p>
    <p>強制 LTR：<bdo dir = "ltr">1234 السلام</bdo></p>
    <p>強制 RTL：<bdo dir = "rtl">1234 السلام</bdo></p>
```

## `<!---->` - 註解

* **非自關閉** 標籤  
* `<!--` 和 `-->` 之間的內容會被當作註解，不會顯示在網頁上
* 範例  
```html
    <!--單行註解-->
    <!--
        多行
        註解
    -->
```
