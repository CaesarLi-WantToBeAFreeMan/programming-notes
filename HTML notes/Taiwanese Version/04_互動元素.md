## `<a></a>` - 錨點元素（超連結）

* **非自關閉** 標籤  
* 用來定義超連結，讓使用者可以跳轉到其他頁面或資源  
* 在所有瀏覽器中，超連結的預設外觀如下：
    1. 未拜訪過的連結是藍色加底線
    2. 拜訪過的連結是紫色加底線
    3. 活動中的連結是紅色加底線
* 常見的本地屬性：
    1. `href` – 定義目標 URL 或檔案
        * 範例：
        ```html
            <a href = "https://www.google.com/">拜訪 Google</a> <!--連到網頁-->
            <a href = "#topic-1">跳到主題 1</a> <!--跳到文件中的某個 ID-->
            <a href = "example.pdf"></a> <!--連到一個檔案-->
        ```
    2. `target` – 指定在哪裡開啟連結的內容
        * 可用值：
            1. `_blank`  
                * 在新視窗或新分頁中開啟  
            2. `_parent`  
                * 在父框架中開啟  
            3. `_self`  
                * 在同一個框架中開啟（`預設值`）  
            4. `_top`  
                * 在整個視窗中開啟  
            5. `frameName`  
                * 在指定名稱的 iframe 中開啟  
        * 範例：  
            * 請參考 [mainFrame](../Examples/04_mainFrame.html)
    3. `download` – 下載文件
        * 下載相同文件  
            * 範例：
            ```html
                <a href = "PDFs/04/example.pdf" download>下載範例 PDF</a>
            ```
        * 下載不同文件  
            * **不支援** `Google Chrome` 和 `Mozilla Firefox`  
            * 範例：
            ```html
                <a href = "https://www.google.com/" download = "PDFs/04/example.pdf">下載不同文件</a>
            ```

## `<button></button>` - 可點擊的按鈕

* **非自關閉** 標籤  
* 用來建立網頁上的可點擊按鈕  
* 本身不會執行任何動作 —— 需要搭配 JavaScript 才能有功能  
* 我們會在 `form` 章節進一步討論它的屬性
