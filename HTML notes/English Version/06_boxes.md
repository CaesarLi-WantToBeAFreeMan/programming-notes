## Box Types
* There are three box types:
    1. `block`
    2. `inline`
    3. `inline-block`
* Define how element behave in the layout
* Every element becomes a rectangular box in the browser

## `block`

* Always start on a new line, browsers automatically add some spaces (`margin`, **watch CSS note**) before and after the element
* Always take up the full width available
* Elements
    * text
        1. `<h1></h1>` to `<h6></h6>`
        2. `<p></p>`
        3. `<pre></pre>`
        4. `<hr>`
        5. `<figcaption></figcaption>`
        6. `<noscript></noscript>`
    * container
        1. `<header></header>
        2. `<nav></nav>
        3. `<main></main>
        4. `<div></div>
        5. `<article></article>
        6. `<section></section>
        7. `<aside></aside>
        8. `<blockquote></blockquote>`
        9. `<fieldset></fieldset>`
        10. `<figure></figure>
        11. `<footer></footer>
        12. `<address></address>
    * list
        1. <ul>
        2. <ol>
        3. <li>
        4. <dl>
        5. <dt>
        6. <dd>
    * table
        1. <table>
    * form
        1. <form>
    * multimedia
        1. <video>
        2. <canvas>
