## introduction

* `Lua 5.1` script engine is built in `Neovim`

## configuration structure

### configuration location

* `init.lua`: initual configuration file of `Neovim`
* `~/.config/nvim/init.lua` for `Linux/Apple MacOS`
* `~/AppData/Local/nvim/init.lua` for `Microsoft Windows`

### recommended configuration structure

```txt
    ├── init.lua
    └── lua/
        ├── config/
            ├── options.lua     vim options
            ├── keymaps.lua     key mappings
            ├── lazy.lua        modern plugin manager
            └── autocmds.lua    vim autocommands
        └── plugin/
            ├── neotree.lua     neovim's file explorer
            ├── telescope.lua   fussy filder
            ├── lsp.lua         autocomplate
            ├── onedark.lua     colorscheme
            └── ...
```

### basic `init.lua`

```lua
    vim.g.mapleader = "\\"          --use \ as my global leader key
    vim.g.maplocalleader = "\\"     --use \ as my local leader key

    require("config.options")       --load options.lua
    require("config.keymaps")       --load keymaps.lua
    require("config.lazy")          --load lazyvim plugin manager
    require("config.autocmds")      --load autocommands
```

## modules

### `vim.opt` - options

```lua
    --boolean
    vim.opt.relativenumber = true       --show relative line number

    --integer
    vim.opt.tabstop = 4                 --number of spaces per tab

    --string
    vim.opt.clipboard = "unnamedplus"   --use system clipboard
```

### `vim.keymap.set` - key mappings

```lua
    --(mode, keymap, command || function, option)
    --[[
        modes:
            n -> normal
            i -> insert
            v -> visual
            x -> visual block
            t -> terminal
            c -> command
    ]]
    vim.keymap.set(
        "n",                                --in normal mode
        "<C-n>",                            --keymap
        "o<Esc>",                           --commands
        {
            noremap = true,                 --non-recursive mapping
            silent = true,                  --do not show message
            expr = false,                   --expression mapping
            nowait = false,                 --do not wait for more keys
            desc = "add a new line below"   --keymap description
            buffer = 0,                     --0 = current buffer, other is buffer index
        }
    )
```
